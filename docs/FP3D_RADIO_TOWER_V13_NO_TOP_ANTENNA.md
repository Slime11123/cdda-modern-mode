# V13：无线电塔顶部附加天线移除

日期：2026-11-08。用户要求「把顶部那个天线删了」，随后反馈实机画面没有变化。

## 修改的确切范围

正式源码：`src/fp3d_scene.cpp`，函数 `radio_tower_geometry()`。

删除了原 V12 仅在 `top_storey` 时绘制的附加顶部组件：

- 中央竖直天线杆，原高度高于本层顶端 0.70 世界单位；
- 其上的横向天线杆；
- 两侧短设备盒；
- 附加在塔顶的薄金属服务板。

`radio_tower_geometry` 不再接受 `top_storey` 参数，调用点亦同步更新。保留原本的四角主支柱、每层钢制横梁、红色 X 形交叉斜撑和层间连续结构。

**没有更改**任何原版无线电塔地形、场景碰撞、玩家存档、地图平台、相邻建筑地板、其他围栏模型或光影代码。

## 为什么用户截图看不到变化

核查用户游戏的进程及源代码/编译时间：`runtime/0i1/cataclysm-tiles-models-latest.exe` 的进程于 16:38:54 启动，源文件于 16:38:40 修改，CMake 编译于 16:38:51 完成；`runtime/0i1/.models-latest-build.json` 中的源文件二进制哈希也与构建结果相符。因此**不能把本次“没变化”归咎于仅仅启动了旧程序**。V12 的天线总成只在最高层渲染；如果画面中并没有那个最高层新增的天线头，删除后普通塔身不会有任何可感知变化。用户看到的其他悬浮平面或主塔结构属于不同部位，不能未经确认就删除地图真实的上层地板。
