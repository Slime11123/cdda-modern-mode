# 3D 入场资料面板

2026-11-01。

参考用户提供的 `11月1日.mp4` 与截图，实现中央白字、分隔线、灰色字段名、柔边暗色衬底。参考视频仅约 5.5 秒，最后仍显示面板；渐隐按用户明确要求补齐，未声称视频包含完整退场过程。

3D 模式下新建角色或成功加载存档时播放一次。标题先显现，日期与五行资料以 100 毫秒间隔跟随，各自渐显 900 毫秒；最后一行在 1.5 秒完全出现。完整停留 3.5 秒，全部内容再共同渐隐 1.5 秒，总长 6.5 秒。

资料来自当前角色与原版系统：从 `calendar::start_of_game` 起算的天数、原版季节历日期时间、姓名、自定义或原版职业、当前位置描述、当前天气及按用户单位显示的当地温度、原版总击杀数。去除位置文字的颜色标记和模组来源行。长内容适配面板宽度。

计时从首个可见世界帧开始，不消耗游戏回合。菜单、2D 和窗口失焦时隐藏并暂停计时，恢复后继续；播放完不会因普通行动、开关背包或模式切换重复播放。返回主菜单或释放渲染器时清理状态。面板不接收输入，不创建阻塞弹窗。暗色衬底为一次生成的小纹理，不读取场景画面；这次未实现背景场景模糊。

代码位于 `src/fp3d_entry.h/.cpp`，在 `game::start_game()` 与成功的 `game::load()` 末尾触发，经 `sdltiles.cpp` 世界/HUD 绘制后叠加。渲染完成恢复缩放、裁剪、绘制颜色与混合状态。ON/OFF 均可构建。
