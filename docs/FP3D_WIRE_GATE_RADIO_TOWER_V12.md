# CDDA 3D V12：铁丝网门、围栏与无线电发射塔模型

日期：2026-11-08。依据用户五张实机截图，对应原版 `t_chaingate_l`、`t_chaingate_c`、`t_chaingate_o`、`t_chainfence` / `t_chainfence_posts`、`t_radio_tower`。

## 已在正式工程实现

1. **铁丝网大门**（`src/fp3d_scene.cpp`）不再依靠原版俯视图块当作 3D 立面。保留不随开关移动的两根锚柱、钢质上横梁、铰链侧立柱、锁扣及锁门专用锁具。活动门扇包含双立柱、上下边框和中间横梁，额外两根有真正三维厚度的 X 形斜撑。
2. **开门状态**整扇 0.76 格宽的门板绕左固定铰链转约 88 度，门框与菱形网面都跟随旋转，不会像截图中只剩几根金属杆；门锁、可通行与原版 `ACTION_OPEN` / `ACTION_CLOSE` 行为保持不变。
3. **闭门和锁门状态**有完整门扇与可见菱形钢丝网，锁门额外给金色小锁，纯视觉状态来自原版地形 ID，绝不根据 3D 画面自行修改地形或门的权限。
4. **围栏**改进已有透空菱形金属网的密度（8 列 × 13 行）及线宽，保留已有地基立柱和水平拉杆；不再用整面不透明的图片显示金属网。
5. **无线电发射塔**继续沿用已存在的每层四角立柱、各级连接横梁与 X 型斜撑，在最后一层追加真实 3D 的金属小平台、向上延伸的中央天线杆、两侧水平支架和短定向设备盒，不在每一个连续的 z-level 上反复生成天线头。
6. **无线电塔悬浮板/贴图问题**：原版塔架 `t_radio_tower` 的 2D 图块不再直接拿去绘制地面砖；改用普通混凝土地面材质。如果是透空塔架，也不再额外画一片完全不受支撑的整格天花板；仍保留其他真实楼层、地图平台的正常地板绘制（不能随意删除地图结构）。
7. **准星与性能**：在 `src/fp3d_snapshot.cpp` 将原版开门的拾取代理与绕左铰链旋转到后方的门扇位置同步，同时把固定上横梁加入拾取；普通围栏和塔仍采用原来基于真实地形 ID 的查询路径，模型进入已有的 OpenGL chunk display list 缓存。无线电塔顶部增加了实际高度对应的区块可见性半径。

## 修改文件

- `src/fp3d_scene.cpp`：实心钢管、活动门扇、真实网面、无线电塔顶部、地面/天花板材质。
- `src/fp3d_snapshot.cpp`：开门后位置的门扇拾取代理、固定横梁，兼容原版射线交互。

**没有修改**原版 `data/json`、世界存档、玩家配置、贴图包、车辆/AI 逻辑、道路地图结构、其他 Agent 正在编辑的光影/阴影代码，也没有提交或推送 GitHub。
