## 已接入的操作

仅在 3D 世界中使用独立 FP3D 按键配置；2D 和原版菜单仍使用各自配置。F6 可修改并通过原版配置文件保存独立键位。

| 默认输入 | 行为 |
|---|---|
| WASD | 步行按镜头方向移动；实际控制车辆时映射原版油门/倒车/转向方向，不随镜头转动 |
| 鼠标 | 观察，不执行等待动作 |
| E / 长按 E | 前方相邻格智能交互 / 合法操作列表；门、容器及可见 NPC 走原版执行链 |
| F / 长按 F | 快捡目标格顶层单件 / 直接打开附近物品面板 |
| 左键 | 可见相邻生物的原版近战移动攻击；按住逐次经原版动作循环结算 |
| 右键、持枪左键 | 进入原版瞄准/射击界面，由原版处理射击模式、瞄准时间和命中 |
| R | 原版装填手持武器 |
| 左 Shift / 左 Ctrl | 原版切换奔跑 / 蹲姿 |
| Tab | 综合生存面板；Esc 或 Tab 返回；搜索文字输入时 Tab 不抢占输入框 |
| 1–8 / 滚轮 | 选择快捷栏并通过原版持握动作切换物品 |
| M / Q / 空格 | 现代地图 / 半透明快捷行动轮盘 / 原版等待一回合 |
| 按住左 Alt | 展开状态；松开折叠；失焦清除状态 |
| F5 / F6 | 切换 2D/3D / 操作配置 |

E/F 长按初值 250 ms，短按在松开时识别，长按触发后松开不会再次提交短按。左键每次只在原版请求下一动作时提交一次。菜单、失焦与 F5 释放捕获时清空手势。3D 输入等待和界面刷新不提交原版等待动作，且不采用原版可选的墙钟时间行动点附加扣除。

## Tab 背包与 HUD

- 同一 SDL2 窗口与 ImGui 客户端；1080p 显示装备、个人物品、附近物品三栏；720p 把物品/附近改成切换抽屉。顶部导航、侧边分类、独立滚动、关闭按钮与 100/125/150% 缩放已接入。
- 真实手持和多层穿戴清单；真实 CONTAINER 口袋、容量/用量及嵌套 item_location；附近地面、打开的家具容器与车辆储物格。封闭、不可见、超距、跨层、工作中的车辆清洗储物格不会作为可取来源。
- 图块包物品图标、数量、耐久、独立搜索和分类、共同排序、悬停摘要、双击/右键完整原版物品详情、右键数量选择、整组拿取、Shift 多选及拖拽。
- 拖到口袋分组使用指定内部口袋，容量不足不会改放到其他口袋；拖到装备区域持握或穿戴；右键拾取、放到脚下、脱下、使用及快捷栏分配。转移期间保留同一面板显示并暂时禁用操作，交还原版世界/活动结算后刷新，不在冻结世界中免费搬运。
- 物品请求重新验证位置、数量、封闭父口袋及实际持有者；拒绝重复/父子重叠批量目标与容器循环引用。拾取、丢弃、装入分别复用原版活动；物品使用调用 avatar_action::use_item，持握与装入保留原版所有权检查。
- 图标是菜单自有 SDL 纹理，关闭时释放；3D 背景使用 GPU 内复制，不从显存读回到 CPU。图标不借用会随世界图集扩容而失效的 UV。
- HUD 显示生命、耐力、姿态、枪械弹药及 8 个快捷栏名称；Alt 展开属性/身体状态。导航读取原版旅行终点或当前任务，显示相对方向、大地图距离及楼层差，可在地图页关闭；不创建新的寻路/移动规则。
- 快捷栏分配、页面、缩放和导航开关目前是会话设置，返回标题清除快捷栏。没有改变世界存档格式。

## 建造、地图与 NPC

Tab 的建造兼容入口保留原版项目搜索与材料/技能/亮度/阵营检查；选定项目后，3D 中以红/绿半透明占位体预览相邻目标格，鼠标转头选择，E/左键确认、Esc/F5 取消。预览只有表现数据，确认后回到原版 place_construction 的材料消耗与 ACT_BUILD 活动。预览的高度区分地面、家具和墙体，目前不是每种构造的精确完成模型。

自动回归分别执行 `cata_test-tiles.exe '[fp3d]'`、`'[.fp3d_gl]'` 与 `'[construction]'`，参数 `--rng-seed 424242 --user-dir=<隔离 QA 目录>`。图形测试额外设置 `CDDA_FP3D=1`、`CDDA_FP3D_START_ACTIVE=1` 和 `CDDA_FP3D_RENDER_REPORT_DIR=<证据目录>`。
