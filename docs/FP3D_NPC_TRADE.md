# NPC 交易：生存背包样式

2026-11-01。3D 模式的 NPC 交易改为与生存菜单背包一致的双栏图标网格，白色文字、暖黄色强调、半透明底色，保留冻结的 3D 场景背景。按后续反馈，左栏为玩家可出售的物品，右栏为 NPC 商品；买卖归属、数量和价格逻辑保持原有含义。

## 使用

- 单击卡片加入一件，再次单击移除；悬停查看全名、单价、数量、重量、体积与位置。
- 每栏可搜索、选择与背包相同的九类物品，并筛选已选物品。
- 下方滑条、减号、加号、全部、移除可用鼠标调整数量；“配平”沿用原版按当前物品补足交易的方法。
- 不愿买卖或不能脱下的装备置灰，保留原版拒绝原因。
- 底部显示购入、出售和债务/盈余；启用原版银行选项时显示银行结算。
- 确认交易后用鼠标完成二次确认，或返回调整；返回对话直接取消。
- 沿用生存菜单的缩放选择；720p 的 150% 缩放使用紧凑卡片与数量区，两栏仍可独立滚动。

## 实现边界

`fp3d_trade` 只负责展示并排队操作。`process_action` 在绘制回调之外调用原版 `trade_selector`；返回原版 `trade_result_t`，最终物品转移、现金、欠款与经验仍在 `npc_trading::trade` 中执行。

候选物品仍由原版角色/附近物品/商店区域收集，并使用原版所有权、价格、出售/收购意愿和容量/信用检查。选中容器或其内容时清除相互冲突的选择，防止重复计价与转移。浏览、选择和确认预览保护随机状态，不推进游戏时间或消耗行动点。

3D 功能关闭或处于原版模式时继续使用原版交易界面。此前的鼠标 NPC 对话与头像界面包含在本次运行包中。

构建时还修复了工作区已有 HUD 改动中的两处编译问题：重复的迷你地图尺寸变量和调色板访问；没有重写其他 HUD 功能。

## 滚动性能修正

用户反馈移动鼠标和滚动时卡顿。原界面每帧遍历、格式化并提交所有物品卡片的边框、图标和文字，屏幕外项目仍产生绘制顶点。现缓存筛选后的分类列表，用 ImGuiListClipper 按网格行跳过屏幕外项目，单个卡片额外检查可见性；图标只在首次可见时生成并缓存。筛选和选中状态改变时重建列表，保持原版价格、交易数量和容器冲突处理。

千件 NPC 商品、1920×1080／100% 的隐藏 SDL/OpenGL 对比：UNDEAD_PEOPLE_BASE 平均每帧 142.265 → 1.19679 毫秒，retrodays 为 148.210 → 1.35634 毫秒；提交顶点由 70436 降为 8244。耗时为本机该测试场景的结果，不代表完整游戏或其他设备帧率。测试检查列表顶部和底部的绘制量、完整滚动范围，以及原有筛选、数量、价格、确认和取消流程；两种贴图、两种分辨率、两档缩放共 4432 图形断言通过。

证据：`qa/npc-trade-performance/`。`baseline-images/*-trade-performance.csv` 为优化前，`final-gl-images/*-trade-performance.csv` 为最终结果。首次新增滚动测试在移入目标网格之前发送滚轮，修正测试事件顺序后通过。运行包：`runtime/npc-trade-smooth/`。

交易／对话专项 `[npc_trade],[npc_talk]` 为 37 用例／578 断言通过；图形回归 4432 断言通过，ON 和 OFF 构建通过。完整 `[fp3d],[npc_talk]` 回归的 144 用例／8650 断言通过，但进程因原有存档读取 `active_mission` 等字段的错误日志退出非零，不能记作完整回归通过。优化前的完整运行还复现了制作目录测试依赖学习配方的顺序问题；共享工作区随后已有其他修改给该测试显式学习配方。本次仅修改交易窗口和对应图形测试，没有修改制作或存档逻辑。原始失败日志均保留。

共享构建目录曾与其他任务同时链接测试程序而遇到文件占用，性能对比改用独立复制的测试程序；最终标准测试目标构建通过。OFF 构建遇到旧生成配置带入 `/MANIFEST:NO`，按 UCRT64 环境重新生成并构建通过。两个根目录 3D 启动器现均指向 `npc-trade-smooth`，退出旧进程后重启生效。
