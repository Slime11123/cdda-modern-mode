# CDDA 3D：白天室内补光和雨天地面连续反射（v6b）

更新：2026-11-08。本版本属于 CDDA 自研 Photon 光影视觉桥，不是原版 Iris/Photon 全部多 Pass。

## 实现改动

- src/fp3d_scene.cpp：日间环境照度只依据原生时间和天气，减少背光空间过暗，不再由玩家是否在室内控制整屏照度。雨天铺装/道路反射遮罩覆盖连续的 1 米格子并轻微重叠，消除相邻地形原来每格 3cm 左右的漏反射缝。
- src/fp3d_compositor.cpp：材质反射缓冲支持线性边界过滤，同时共享原本的场景深度，反射不会穿过墙体和车身。
- src/fp3d_mcshader.cpp：真实水平路面采用连续湿润薄膜作为基础反光；镜面 SSR 保留但变弱、做少量空间滤波，屏幕空间命中距离从 15 米到 36 米逐渐淡出，避免原版约 20 米的硬截断，雨天道路不再以方块断裂形式发亮。水面可以独立于下雨反射。
- src/fp3d_shaderpacks.cpp：太阳阴影处保留适量日间间接天光，防止室内遮阴区域被阴影后处理乘得太黑；日照为零时不补光，太阳直射地面不会被额外整体提亮。
- 维持原来的路灯、邮箱、家具和车辆太阳阴影模型。没有改变玩家存档、CDDA 原版天气/回合机制、2D 模式或光影 ZIP 内容。

## 验收

- Windows UCRT64，ENABLE_FP3D ON 编译链接 exit 0，新程序：runtime/modern-3d-shaderpacks/cataclysm-tiles-daylight-wet-v6b.exe。原版本保留。
- NVIDIA RTX 4080 SUPER OpenGL 4.6：Photon 1.4 光影桥、简单 Minecraft final.fsh、HDR/深度缓冲、60 次 FBO 缩放、PCF 太阳阴影和错误 GLSL 回退通过。
- 深度 SSR GPU 回归：湿地改变 7,434 个像素；晴天水面仍会反射；未标记干地面差异为零；玩家室内外状态改变后 SSR / 体积光像素最大差异 0。
- 实机 ShaderDaylightLab：2520×1392、4 辆车、156 个可见车辆部件、30 个家具太阳遮挡体（包括 5 盏路灯）。模拟雨天（仅抓帧环境变量，不修改原生天气或存档）有 1,484,014 个路面反射像素，反射贴图及阴影贴图的 OpenGL 读回错误均为零。截图：qa/v6b-daylight-wet-road-photon.png。
- 车库屋檐下的干燥日照画面平均 RGB：旧 v5 约 95.03/114.54/125.02，新 v6b 约 104.59/124.41/135.83，合计平均亮度提高约 9%。同一画面无遮阴的中心道路平均 RGB 仍约 78.94/75.72/73.48，几乎没有变化。截图：qa/v6b-daylight-bounce-dry-photon.png。
- 模拟玩家进入室内后的真实游戏抓帧：窗外场景亮度比约 1.0000006，路灯阴影深度贴图保持不变；临时禁用家具阴影后，太阳阴影深度像素数从 422842 降到 416472，深度哈希不同。
- 所有 QA 光影偏好文件检查结束后均恢复其原始字节。
- QA 启动曾有 1 次 Windows 0xC0000005 访问异常（发生在完整 3D 场景生成前），随后连续两次湿路 3D 抓帧成功；该偶发异常还未定位，不应声称已修复。

## 现存限制

- 这不是全局光照 GI，也没有真正的多次室内反弹、透玻璃光学模型或完整原版 Iris/Photon 渲染程序。日间室内补光是稳定的近似。
- SSR 不能反射视野外或原版不可见的几何；自定义地面 terrain ID 和特殊雨天材质还需后续扩展。
- 真正封闭房间、下雨阴天、雨夜、复杂多层建筑及游戏整机帧率尚未覆盖全部实机地图；目前的室内回归是室内状态模拟和现成屋檐下场景，而不是逐个房间手动验收。
- 本轮不执行 Git 提交或推送，也不上传任何第三方 Photon 原版光影包。

## 启动方法

原 启动3D操作修复验证.cmd 已指向 cataclysm-tiles-daylight-wet-v6b.exe。退出正在运行的旧游戏后双击 CMD 即可。F5/F6 的光影选择和独立的湿地 SSR/体积光开关保持原样。
