# 不死人家具第二轮模型修复（2026-11-07）

适用范围：CDDA 0.I-1 / ENABLE_FP3D。基于本地 `MSX++UnDeadPeopleEdition` 的 `normal_furniture.png`（可视查证的 32×32 原版图块），只更改 3D 表现，未改游戏逻辑、物体碰撞和地图数据。

## 五类已修复对象

| 家具 | 问题根因 | 已落实的修复 |
|---|---|---|
| 自动售货机 | 立式机身侧面裁剪了贴图透明/黑边（图片实体宽度约 x=6..24），且贴纸被整块铺到立面 | 重采红色机壳，顶盖、商品窗、投币/操作面板、出货口和底部踢脚板独立几何；商品图片只显示在商品窗前面 |
| 展示柜 | 把画有玻璃的上半张 2D 贴图当作不透明实心盒 | 抽屉底柜、台面、展示底板、四立柱、盖板、四块半透明玻璃面；新 `part::glass` 用 OpenGL blending、关闭深度写入及显式恢复绘制状态 |
| 文件柜 | 从真实 sprite 左侧 x=3..6 的空白阴影取样，使侧面黑；正面抽屉被拉成长平面 | 正确取样已绘制的金属区域 x=10..15，顶板单独裁剪；正面三个抽屉实体几何和各自贴图 |
| 铁砧 | 贴图 y=13..17 位于剪影上方空白处，所以几乎全黑；形体是直立柱子 | 金属材料从已绘制的 y=19..27 内取色；重做底脚、细腰、肩、工作面、凸出砧角和砧尾 |
| 窑炉 | 石窑源图 y=12..16 是透明区，被当作黑色石墙；石窑与钢铁窑复用错误形体 | 石窑的材料重采 y=19..28，圆形砖体、炉沿、顶部烬火、正面炉口；钢铁窑独立 `metal_kiln`，金属滚筒、烟囱、检修门与控制指示灯 |

## 源码

- `src/fp3d_furniture.h`：增加 `part::glass` 与末尾形态 `metal_kiln`，保留旧枚举顺序。
- `src/fp3d_furniture.cpp`：针对性重建 5 类几何及变体关系，并更新物品放置高度。
- `src/fp3d_materials.cpp`：根据实际像素内容裁剪顶面、正面、侧面、炉口、把手等，不再误采透明边缘。
- `src/fp3d_scene.cpp`：用 OpenGL 固定管线的混合材质绘制薄玻璃，前后保存并恢复图形状态。
- 源码保留其他正在开发的未提交更改，**没有 git commit / push**。

## 本地验证与文件

- 编译：CMake/Ninja `cataclysm-tiles`，`BUILD_EXIT=0`。
- `--help`：退出码 0；`--jsonverify --basepath ...`：退出码 0，stderr 空。非致命字体缺失提示只出现在数据校验 stdout。
- 新版测试包：`runtime/modern-undead-furniture-v2`（未覆盖旧版 `modern-undead-furniture`）。
- 运行入口：工作区根目录 `启动不死人家具模型修正版.cmd`。
- 旧版预览：`qa/undead_3d_models_preview_1.png`、`_2.png`。
- 新版预览：`qa/undead_3d_models_fixed_v2_1.png` 和 `qa/undead_3d_models_fixed_v2_2.png`。
- 真实原图网格检查：`qa/undead_target_sprites_grid.png`。
- 新预览根据**实际 C++ part 数据**和与当前 UV 调整同步的纹理裁剪渲染；它们是 **离线预览，非游戏实机截图**，不模拟游戏本身的透明排序及全部光照。

## 尚需实机视觉验收

进入游戏 3D 模式后，从正面、侧面及略俯视角度检查售货机货品窗、玻璃柜的半透明度、文件柜抽屉、铁砧轮廓和石/金属窑炉面。复杂透明面在本项目的 GL 固定管线下可能仍需进一步处理遮挡排序。未经实机截图检查，不声称五项在所有地图及显卡上视觉完全正确。
