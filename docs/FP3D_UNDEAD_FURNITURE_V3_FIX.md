# 不死人家具第三轮：展示柜、文件柜、石窑炉（2026-11-07）

## 已直接实施的修改

- **展示柜 `f_displaycase` / `f_displaycase_b`**：删除旧玻璃上罩、展示柱、玻璃面，只保留矮柜箱体、两个**实体抽屉前板**与顶板。柜体总高改为 0.79（渲染比例）；两个抽屉使用 `normal_furniture.png` 原图下半部分的不同区域；顶部不再截取抽屉把手。
- **文件柜 `f_filing_cabinet`**：由 3 层扩成 **4 层独立抽屉**，维持每层相近高度和间距。最底层确有专门的几何；在四个立面上复用来自贴图有效像素的抽屉把手样式。总高改为 1.82。
- **石窑炉 `f_kiln_empty` / `f_kiln_full` / `f_clay_kiln`**：旧版顶部是实心棕色盖板，炉膛与炉壁不成结构。新模型有实体基座、暗色炉膛底、位于炉沿以下的炭床、独立后墙与左右墙、左右前门柱、横梁、前炉口以及**分离的四条上沿石梁**；中央不再有实心封盖。石砖取样严格在不死人贴图的已绘制灰石区域，暖色火焰只用于炉腔底面和正面炉口。不使用 `round` 去强行把低石窑变成圆桶。
- **金属窑炉保持此前独立的 `metal_kiln` 造型**，此次没有改动其烟囱及门板模型。

- `src/fp3d_furniture.cpp`：仅三种目标的几何体、物品展示高度。
- `src/fp3d_materials.cpp`：对应不死人贴图的分面 UV。
- 不改其他并发开发中的游戏文件；不修改原版的物理、任务、建造、地形和存档数据。
- 离线预览程序单独复制为 `qa/render_undead_furniture_fixed_v3.py`，纠正其不具有深度缓冲时把下层抽屉盖住的排序缺陷；它只用于生成图片，**不替代游戏实机验收**。
