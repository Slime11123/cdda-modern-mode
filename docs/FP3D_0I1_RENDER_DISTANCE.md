# 3D 远处渲染距离修正

后续已加入约 960 格的城市建筑轮廓与移动绘制缓存优化，当前交付见 `FP3D_0I1_CITY_PERFORMANCE.md`；下文保留本次历史记录。

日期：2026-10-28。基线 `cad7bc83`；交付目录 `runtime/render-distance`。

## 需求纠正与交付范围

用户所说的视野范围是远处渲染距离。此前把水平视角从 120° 调至 135° 理解错误，本次恢复 120°。上一版地面物品 0.7 的显示尺寸和完整天空背景保留。

目前交付的是分层远景：

- 近处仍为原版 60 格范围的真实地形、建筑、家具及可见生物，并保留上 4 / 下 2 层精细场景。
- 新增约 240 格半径的简化室外地表远景，覆盖草地、道路、水面和林地树木轮廓。数据来自已经生成的大地图地表类型，无需先在 2D 探索。
- 远平面从 96 扩大到 384，足以覆盖方形远景角落；超过远景的空白仍由昼夜天空背景填充。

这不是把整个真实游戏加载区扩大四倍：远处房屋细部、室内、家具、车辆、生物及物品仍不在远景层中，特殊地形暂以普通地表代替。道路是粗略地表块，树林是简化树卡片，接近后换成真实地图细节。原版怪物活动、交互和人物感知范围不因此扩大。未声称 240 格内所有对象均已精细呈现。

## 实现与边界

- 每个远景块最多 12×12 格；以绝对世界坐标对齐，避免走动时远处纹理和树木随玩家滑动。与近处 60 格区域相交时精确切开，减少重复地面和接缝。
- 远景地面略低于精细地面，并使用正常深度遮挡。墙体能够挡住远景。两套原生图块共用现有材质来源，林地继续使用透明前景 X 形树卡片。
- 只读现有大地图类型，不生成新的地图，不查询远处物品或生物，不改变探索记录、游戏时间、世界随机数或玩家位置。没有现有大地图数据的区域仍显示天空。
- 天空不可见、地下、失明以及夜间光线不足时不启用地表远景；夜间继续由原版近处感知和夜空组成画面。远景层不照亮本来黑暗的区域。
- 日志新增 `landscape_patches`，便于区分精细地形采集与远景数据。
