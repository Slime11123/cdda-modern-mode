# CDDA 3D 车辆 V8：移除车顶上方深色悬浮平面（图形层过滤）

日期：2026-11-08。针对用户指出的、红色汽车顶部悬浮一片暗棕色木纹板的显示 BUG，在正式 3D 画面渲染器中直接实现有边界的过滤，而不是改变存档、车的模型高度或删除地图内的真实上层建筑。

## 原因检查

现有 `src/fp3d_vehicle_renderer.cpp` 中，V7 车顶使用纯色车漆的无贴图 `cuboid()`，**不可能直接生成用户图中的木纹面**。本机 `src/fp3d_scene.cpp` 会使用当前图块包绘制地图上层地板或下层房间的天花板；相邻 Z 层相隔 2.2 个游戏世界单位，而 V7 汽车的车顶位于约 1.93 世界单位，高度相差约 0.27，符合「板子紧贴在汽车上方」的画面。

这说明应优先过滤可能被额外渲染的孤立上层楼板/天花板，而不能直接隐藏全部 3D 车顶、所有上层地板或禁用高度层。**尚未在用户当时的精确地图坐标处取得逐 draw call 追踪，因此这是经过源码定位的定向修复，而不是已被实机证明的唯一根因。**

## 本次实际修改

**文件：`src/fp3d_scene.cpp`**，保留其他 Agent 修改过的渲染功能。

1. 仅对地图场景中的**真实车辆快照**构建过滤遮罩。要求整车至少有 4 个车架零件和 1 个未损坏的原生 `ROOF` 部件；没有这些结构的自行车、简易车架不会误触发。
2. 车辆位置通过原版 `part.mount` 和 `pivot` 以及车体转角映射到世界 X/Y，不能直接按车辆世界包围盒全区域删除。
3. 必须在真实道路、铺装路面、人行道或沥青地面（如 `t_pavement`、`t_road` 等）上方才候选；建筑内正常地板不处理。
4. 若车辆上方存在没有真实对应上层地板的**额外底层天花板面**，隐藏这块多余的 ceiling quads。
5. 若上层高度格存在一小片带木纹或屋顶类 ID 的完整地板，按四邻接关系搜索其整片连通区域。只过滤最多 16 格、周围**没有墙/窗/门/楼梯**的独立疑似浮空板；真实大面积建筑二层、桥面不删除。
6. 原版地图 Z 层的实际存在性、楼层碰撞、驾驶物理和存档不变。隐藏仅在 OpenGL 画面 `draw_cell()` 中实现。
7. 过滤后的布尔状态写入 terrain chunk 的 `signature`。车辆离开、转弯或重新进入附近时触发网格重建，避免旧编译列表把多余板子继续缓存。
8. 修复回归发现的提前中止搜索问题：即使某一部分已发现墙体或跨越 16 格，也必须完整遍历已连接的楼板；不会把另一部分同一楼层误判为孤立板。

源码检查、模拟/结构回归、编译和命令行 JSON 校验都已通过；**尚未在原截图位置实机拍摄 V8 的相同相机画面进行验证**。因此不能把这份修复误称为「所有深色平面都消失」。若那片悬浮面其实是来自非地板绘制通道、或不满足道路/独立楼板条件，需要用相同地图坐标的 3D 画面和场景日志进一步定位。
