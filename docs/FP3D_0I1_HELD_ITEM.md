# 第一人称手持物品

2026-10-27，新增 3D 画面右下方的手持物品显示，直接使用当前图块包的物品前景。空手不显示，装备、放下及更换物品后随原版世界画面刷新。使用倾斜的镜头固定贴图面，保留原素材比例，并朝向画面内侧；这版没有另造手臂或攻击动画。

游戏线程通过原版 `get_wielded_item()` 读取装备，只把物品 ID、变体及必要外观复制到自有快照。已知的自身装备不依赖世界可见性缓存，失明时隐藏。地面物品与手持物品共用 ID / 变体复制方法，但图集键不同，手持图不带地面阴影；解析沿用季节、物品变体及静态 `looks_like` 回退。缺图使用已有备用图案。

材质复用现有图集，不每帧读回或上传图片；新装备在资源请求中优先，图集满且装备未缓存时重建一次，避免新装备因容量被遗漏。镜头物品在世界绘制之后、准星之前画出，深度独立，位于地图窗口内，不占侧栏，也不会在 2D 或菜单中叠加。

## 验证与使用

- `qa/0i1/held-item-cpu.log`：23 用例、708 项断言通过。新增空手→匕首→空手→锤子的原版装备读取、自有快照不随旧物品删除而失效、失明隐藏、位置/时间/行动点/耐力/世界 RNG 不变。
- `qa/0i1/held-item-gl.log`：232 项实际 OpenGL 检查通过。UndeadPeople 与 RetroDays 都实际解析并显示匕首和手枪；检查画面变化仅发生在下方手持区域、准星保持、放下后恢复原场景，并保留人物比例、植物、遮挡、天空及远景回归。
- `qa/0i1/held-item-gl/UNDEAD_PEOPLE_BASE-held-knife_combat.png` 与 `UNDEAD_PEOPLE_BASE-held-glock_19.png` 已目视检查，使用真实图块前景，未生成新贴图。
- `qa/0i1/held-item-build.log`：运行程序构建通过。启动器已指向独立 `runtime/held-item`，哈希记录见 `held-item-delivery.json`；用户目录、中文、图块与两套操作配置继续沿用。

保存退出当前游戏后重新打开“启动3D技术验证.cmd”，用原版装备操作拿起物品即可。没有改变装备动作、物品功能、战斗逻辑或存档格式。
