# 窗户模型与贴图修复

日期：2026-10-27。修复基线 `a5938d1d`，交付目录 `runtime/window-fix`。

## 原因与改动

用户截图中的窗户沿用了门框几何：整张窗户图分别铺在地面、上横梁、侧柱及中部玻璃箱体。窗户中段只覆盖 0.6–1.4 米，上部另有空隙；多楼层下重复图案和空洞尤其明显。

本次将窗户单独建模：

- 窗台下墙体高度 0–0.9 米，窗洞 0.9–2.1 米，上墙体延伸至 3 米层高；补齐上窗楣底面。两侧为细窗框，窗洞宽 0.84 米。
- 下墙、上墙和侧框使用已知相邻实体墙的材质；没有已知实体墙时使用普通墙面。窗下地面使用中性地板材质。它们不再使用整张窗户图案，也不读取隐藏邻居的实时墙面。
- 贴图包的窗户前景仅在窗洞中绘制一次。新建透明前景材质槽，不混入原版 2D 地面背景；只有背景图而无前景的图块使用其原背景图回退。原始贴图包文件未修改。
- 完整透明窗使用薄面玻璃，统一透明系数 0.32。玻璃在不透明建筑和生物之后按距离绘制，保留深度遮挡且不写深度，避免被后画的地形覆盖或遮住窗外本来可见的生物。
- 原版打开/破损、透明且可穿行的窗户保留空洞；窗帘关闭、贴胶带或木板遮挡的窗户使用不透明覆盖面。状态从已授权的地形 ID 的静态定义推导；隐藏窗户仍保持旧记忆状态。
- 室内能通过窗/门看见同层室外时提供天空背景，修复可见窗外上方的一片黑幕；房间墙体、顶面和不透明窗仍负责遮挡，地下和失明门槛保持。

这是一套通用窗户几何，不逐种重建窗格数量或摆开的玻璃扇；不改变原版碰撞、攀窗条件、破坏、行动点或视野授权。上一轮移动性能修复继续保留，追加窗户材质不清空整批建筑缓存。
