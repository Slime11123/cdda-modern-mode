# 2D 现代模式：综合生存菜单

2026-11-03

2D 现代模式按 **Tab** 打开现有综合生存面板，提供背包、人物/健康、制作、建造、地图、任务、队友、更多及侧栏九页。Esc、Tab（或改绑后的菜单键）和关闭按钮均可退出；文字输入获得焦点时不抢占菜单键。F6 的 2D 现代配置可以独立修改菜单键，不影响 3D 配置或 2D 经典操作。

复用现有物品操作、原版活动耗时和完成后自动返回面板流程。制作、穿戴、持握、拾取、转移等操作仍通过现有原版执行链；2D 建造选位置仍使用原版地图。地图、任务、队友与“更多”中的原版兼容入口继续可用。

面板可在从未进入 3D、没有 3D 场景快照的情况下直接打开。不扩大 `turn_based()` 的 3D 控制范围，不启用 3D 移动或准星。2D 面板使用不透明底色以避免原生保留绘图缓冲中的页面残影，不复制此前 3D 背景。中文搜索字段复用现有文字输入支持。
