# 地面物品、宽视角与远处天空修订

后续纠正：用户指的是远处渲染距离，135° 镜头角度已恢复 120°，另加入约 240 格简化地表远景。当前交付见 `FP3D_0I1_RENDER_DISTANCE.md`。本文件保留当时验证记录。

日期：2026-10-28。基线 `bf08413e`；交付目录 `runtime/wide-view`。

## 实现

- 地面物品精灵高度从 0.3 提升至 0.7，宽度等比放大，仍贴地放置并使用图块包原生外观。手持物品 HUD 尺寸不变。
- 3D 水平视角从 120° 扩大到 135°；投影和裁剪共用参数，避免边缘物体提前消失。本次扩大的是镜头角度；地形采样仍为原版 60 格、上 4 / 下 2 层，远平面仍为 96，保留之前的移动优化。实际内容仍按原版感知授权显示。
- 天空从上半球扩展至完整球面，下半球沿用地平线颜色，不再留黑色外圈。白天、黄昏和夜晚继续取原版游戏时间。天空先绘制且不写深度，地面、建筑和生物在其前方正常遮挡；没有地形的远处显示天空，不生成额外地形。
- 原有天空可见门槛保留：室外或室内看到同层室外时启用；失明、地下及完全封闭房间不据此显示室外天空。

## 验证

- 功能回归：33 个用例、1092 项断言通过，退出码 0。含地面物品新尺寸、宽视角裁剪、原版感知一致性与移动场景。
- 隐藏窗口实际 OpenGL：1186 项断言通过，退出码 0，覆盖 UndeadPeople 和 RetroDays。新增位于旧 120° 视角之外的墙体显示检查、0.7 地面物品投影面积大于 0.3 的两倍、空场景白天及夜间整幅无纯黑像素检查。原有地面不被天空覆盖、窗户、生物遮挡、菜单及 F5 回归通过。
- 已目视检查 UndeadPeople 白天地形场景及全天空白天/夜间输出，地形外侧由天空覆盖。
- 同机测试七层采集约 14.2–14.5 ms；连续 12 步含生物场景采集约 16.3–17.4 ms，准备约 9.4–12.3 ms。它们是测试场景的采集耗时，不代表用户存档的整帧 FPS。
- Feature ON 游戏构建和打包通过，代码格式及差异检查通过。本次未重复 Feature OFF 全量构建；新增绘制逻辑仍在既有开关保护内。
