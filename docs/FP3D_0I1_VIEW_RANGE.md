# 3D 视野范围修复

用户反馈：第一人称下可见范围太小，要求独立于 2D 地图的显示范围。

后续视觉修订已将水平视角继续扩大至 120°，下文 100° 为第一次修复记录。当前状态及检查见 `FP3D_0I1_VISUAL_TUNING.md`。

## 原因与修改

原型把场景截在角色周围 12 格，投影远平面为 32 米，并使用 65° 垂直视角。原版侧栏使地图窗口接近正方形时，水平视角也随之偏窄。

- 快照半径改为原版 `MAX_VIEW_DISTANCE`，当前为 60 格，最多覆盖 121×121 格；不随 2D 缩放变化。
- 镜头改为固定 100° 水平视角，垂直视角按实际地图窗口比例计算。
- 远平面改为 96 米，覆盖原版 60 格方形范围的对角方向。
- 按镜头方向、俯仰及窗口比例剔除屏幕外几何；地板改用单个面，减少扩大范围带来的绘制成本。
- 修正斜向观察时精灵朝向相机的横轴，避免某些角度出现侧薄效果。

原版 `map::update_visibility_cache()` 本来就计算已加载地图的可见性，原版图块绘制也准备完整可见范围的地图记忆，无须扩大地图加载或更改角色属性。新快照仍只读取原版判为可见的实时地形和实体；不可见处只允许地形记忆。夜间、失明和墙体等原版限制继续生效，未知地图不会凭空生成。

## 验证

- `qa/0i1/view-range-cpu.log`：18 个用例、598 项断言通过，包含 40 格外地形、30 格外怪物、相机各方向/俯仰/窗口比例，以及原有隐藏信息和只读状态检查。
- `qa/0i1/view-range-gl.log`：实际 OpenGL 离屏绘制通过原有墙体遮挡、精灵透明轮廓、NPC 衣物层叠及 UndeadPeople/RetroDays 切换检查。
- `qa/0i1/view-range-final-gl.log`：最终 68 项断言通过，两款图块均实际绘出前方 40 格及斜向 20×20 格处的墙，证明远处内容通过完整投影与裁剪路径。
- `qa/0i1/view-range-off-build.log` / `view-range-off-check.json`：禁用构建通过，无直接 OpenGL 导入；随后 ON 恢复构建成功。
- 默认 `runtime/0i1` 已更新为验证版本；`view-range-delivery.json` 记录其与独立验证目录的相同 SHA-256。中文及 UndeadPeople 配置保留，双击原有 3D 启动器即可使用。

本次解决原型的人为范围截断与窄镜头。尚未据此宣称所有室内外场景达到 60 FPS；静态合批、增量快照与性能测量仍属于后续 P7。
