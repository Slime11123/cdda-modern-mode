# 三种操作模式

2026-10-31，运行包：`runtime/three-control-modes`。保存退出旧窗口后，重新运行项目根目录的 `启动3D技术验证.cmd` 生效；继续使用 `runtime/0i1/user` 的配置与存档。

F5 循环顺序：**2D经典 → 2D现代 → 3D → 2D经典**。启动器仍默认启动 3D。窗口标题显示当前模式与下一模式。

| 模式 | 当前行为 |
| --- | --- |
| 2D经典 | 原版 2D 世界、菜单、主菜单布局与键位；不应用现代移动或 3D 手势。原版 `?` 按键设置入口保留。 |
| 2D现代 | 独立 `MODERN_2D` 键位配置，默认 W/S/A/D 对应北/南/西/东，不随 3D 镜头转动。暂用原版 2D 界面，其他操作与子菜单沿用原版，后续扩展。 |
| 3D | 保留当前第一人称画面、鼠标视角、现代面板、独立键位与操作。 |

世界中 F6 打开三套配置的选择页。现代模式请使用局部绑定（`+`），配置通过原版键位偏好系统保存。2D现代的 WASD 在世界输入中优先于原版同字母快捷键；Shift 等组合仍按独立绑定匹配。背包、文本输入等子菜单不接管 WASD，也不捕获鼠标。

模式切换会清除待处理的 3D 长按/攻击手势并释放或重新捕获鼠标。两种 2D 模式不绘制 3D 合成画面；经典模式主菜单恢复原版横向布局，切换时重建对应窗口。2D 不再额外采集 3D 场景快照。

验证记录在项目根目录 `qa/0i1/`：

- `three-modes-cpu.log`：67 用例，1996 断言。三模式循环、WASD 方位、原版键位隔离、独立改键保存与已有功能回归。
- `three-modes-gl.log`：实际 OpenGL 检查，1 用例，1188 断言。两个图块包下验证 3D → 经典2D → 现代2D → 3D 的覆盖与画面恢复。
- `three-modes-0i1-final-build.log`、`three-modes-0i1-tests-final-build.log`、`three-modes-0i1-off-modern-final-build.log`：ON 程序、测试程序与 OFF 程序构建。
- `three-modes-package.log`：新运行包生成。
