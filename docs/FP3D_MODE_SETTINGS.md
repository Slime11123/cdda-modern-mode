# 统一模式设置

2026-11-03

游戏内 F5、F6 均打开同一设置窗口，原来的 F5 三模式轮换已移除。

- 画面：2D / 3D。
- 键位：经典 / 现代。经典保留原版按键；现代在 2D 使用独立方向 WASD，在 3D 使用相对视角 WASD。3D 的鼠标转头继续保留。
- UI：原版侧栏 / 现代 HUD，与画面、键位独立。

点击“完成”后立即应用并保存，重启后保留；Esc 或右上角关闭取消本次选择。
“编辑按键”按当前选择进入经典、2D 现代或 3D 现代配置，退出后返回本窗口。具体按键沿用原有编辑器的保存规则。
支持鼠标单选，以及左右选列、上下选项、Enter 完成。采用现有游戏界面主题，三列两行与参考布局一致。

新增 FP3D_VIEW、FP3D_CONTROLS 设置；旧配置没有这两项时，首次启动沿用启动器指定的 2D/3D 默认模式。FP3D_UI_STYLE 原有自动值继续兼容，完成选择后写入明确样式。

验证：八种画面/键位/UI 组合、F5 不再直接切换、WASD 配置隔离，以及实际界面鼠标命中。截图位于 qa/mode-settings/images/mode-settings.png。
