# V10 车辆框架恢复：有厚度的车柱、横梁和门槛

日期：2026-11-08。依据用户 V9 实机侧面截图：「车框架没了」——外侧下部有红色车身和透明玻璃，但中部和前后车窗附近的金属支撑几乎消失，车内的座椅看起来像悬浮。

## 根因

V9 修复了原版 0.I 部件 `halfboard`、`door` 无 `WINDOW` 标记时被错误填成红色实心上半壁的问题，但只在车窗外框处生成约 0.042 本地宽度的单面 `painted_quad` 与只有像素宽度的 `seam()`。这样的窗柱在 OpenGL 3D 斜视角与光照下没有可见体积，车顶、前挡、车门和车内座椅之间失去视觉连接；同时旧上部代码在 `door_open` 时跳过整个固定门框。

## 本次直接修改

正式源码：`src/fp3d_vehicle_renderer.cpp`，无其他生产源码修改。

1. 新增 `cabin_frame_beam(a,b,thickness,paint)`：利用正交法向量为任意斜向两端点生成 6 面有厚度的几何梁。与 V9 的薄纸片和无宽度 `GL_LINES` 不同，梁可在正侧、斜侧和车内视角看到，且使用正式渲染管线中的车漆颜色、光照与阴影深度，不引入单独 OpenGL 渲染器。
2. **固定侧窗框**：对具有原版实际结构支撑且当侧确有未损坏车顶的车身行，按其原版 `frame / door / halfboard / roof / window` 安装格构造 0.092 厚门柱、0.115 厚上窗框和 0.07 厚下窗框，代替 V9 的约 0.042 宽单面平板。完全**不恢复窗洞内的大红墙**。
3. **开门仍保留门框**：车门开闭仅影响原版 `one_part()` 的车门叶，车架由实际底盘/车顶支撑决定，不因 `door_open` 就消失。车门底部原版完好车架处新增约 0.085 厚短门槛梁，保留敞开的门口和车轮拱缺口。
4. **A 柱与 C 柱**：前挡风玻璃的斜前柱、前上横梁以及轿车/掀背车/旅行车的后部连接从薄四边形改为有厚度的漆色斜梁。没有独立后玻璃的车辆仍然不再被整片红板堵住。
5. **真实车顶横梁**：按原版实际完整的每个车顶连续段，在前/后端生成窄的连接横梁。每根都限制在确有完好原生车顶的跨度内，不能跨过原版车顶缺失或拆卸格。
6. **损坏安全性**：以对应侧**最近的原版车顶零件**判定此侧立柱是否可延续到车顶；一侧损坏不可因另一侧完好而伪造完整车架。没有实际原版结构和车顶的开放式 DIY 车辆仍按原来的非封闭车渲染路径。
7. **原版不变**：车辆驾驶/碰撞、坐席安装位置、E 交互、颜色工作台、车门操作、修理、油耗、存档及用户光影设置一律不修改。
