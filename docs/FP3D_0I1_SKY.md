# 天空与昼夜

2026-10-27，新增第一人称天空背景：白天蓝色渐变、日出日落暖色过渡、夜间深色星空。太阳按原版 `sun_azimuth_altitude()` 的方向和高度显示，昼夜过渡沿用同一太阳高度；夜间月亮亮度跟随原版月相。月亮位置采用太阳反方向的装饰近似，不声称精确月球轨道或完整月相轮廓。

天空为以相机为中心的上半球，随转头及俯仰显示，不受角色平移影响。先画天空，再画原有地形；天空不写深度，地形和植物可以正常遮挡天空，未知地面仍保持原来的背景。星星采用固定分布，不消耗游戏 RNG。

快照在游戏线程把当前时间换算为自有天空参数，渲染端不访问世界对象，也不使用电脑时间推进昼夜。游戏回合暂停时天空保持不变，永昼/永夜等原版日照设置由原版太阳计算处理。

只在原版判定角色位于室外、地面及以上、且没有失明时显示天空。室内和地下不绘制天空；从室内透过窗口看天空的局部开口判定仍有待后续屋顶/多层几何支持。本次只改变天空背景，地面照明和天气效果仍属于后续场景工作。
