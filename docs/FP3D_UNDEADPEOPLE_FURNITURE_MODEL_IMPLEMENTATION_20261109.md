# CDDA 3D × 不死人贴图：家具/设施补齐实施记录

日期：2026-11-09

## 任务范围

本轮以当前 0.I 游戏定义和本地 MSX++UnDeadPeopleEdition 图块交集为基线，排除植被、雾气/气流/空实体，保留原版人物、怪物、一般物品的 2.5D 策略。

- 原先已有：46 种家具/设施几何模板，覆盖约 101 个匹配图块 ID。
- 本轮目录输入：308 个非植被未覆盖图块 ID。
- 本轮实体几何映射：296 个 ID；**62 种在本轮实际使用的几何模板**。
- 12 个非实体标识（烟、气流、缺省物及异象等）不转为实体几何。
- 对本次匹配的 462 个家具图块 ID：101 原有模型 + 296 本轮实体 + 53 植被 + 12 非实体 = 462。

**注**：覆盖是源码映射及几何存在，不表示 296 种逐个按原始图完成精细雕刻/游戏实机验收；同一结构的开关、损坏、空满、材质变体复用几何。

## 本轮改动

- `src/fp3d_furniture.h`：注册 `udp_*` 几何类型。
- `src/fp3d_furniture.cpp`：接入新增匹配，保持原有模型优先，`f_counter_gate_c` 使用独立栅门轮廓，不再误用柜台。
- `src/fp3d_furniture_catalog.inc`：根据当前物体 ID 生成的独立 C++ 模型部件及绑定关系。
- `src/fp3d_materials.cpp`：为新增模型划分独立顶面、正面、侧面 UV，避免把含顶部+正面的伪 3D 图完整贴满立方体。对腿、柱、框架采用局部中性材质片段。
- `qa/generate_undead_furniture_catalog.py`：可重复生成模型目录（会覆盖自动生成的 inc 文件）。
- `qa/refine_undead_furniture_models.py`：对特殊物件的结构细化步骤；不能反复运行，对已存在源码的二次修改需审查。
- `qa/undead_furniture_catalog_stats.json`：每个图块 ID 的家族分类与原始统计。
- `qa/render_undead_furniture_gallery.py`：从实际几何数据和不死人原始 PNG 生成对照预览。

## 重点几何

MRI / CT：镂空扫描架与真实检查床；自动医生：分立床台、机械臂和设备支架；静脉输液架：立杆与挂钩。

钻床、带锯、车床、液压机、锻炉、发电机等分别有结构不同的支撑、操作台、机架等部件；不是完整原始贴图简单贴在一个方块上。

安全柜、玻璃柜、垃圾桶、垃圾箱、淋浴设施、天线、风车、炉桶、医疗设备和室内日用品使用专属几何家族。

植被保留原始交叉 Billboard；非实体气流保留游戏原生视觉，不产生厚实体。

## 后续视觉验收

需要在 3D 实际游戏中逐项验证：实际贴图选择、顶部/正面拆分是否准确、正确尺寸、朝向、无遮挡与透明度、建模是否穿模、场景光影、背包/地面物品高度、各类状态的开关行为，尤其需要检查复杂工业/外星器物，不能把静态映射覆盖当成高精度建模全部验收。
