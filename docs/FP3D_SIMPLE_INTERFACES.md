# 3D 简易界面改造进度

更新：2026-11-04。当前优先任务为 3D 窗口适配，原现代操作计划的未完成项继续保留。

## 本批已接入

| 窗口 | 3D 下的表现 | 保留的游戏规则 |
| --- | --- | --- |
| 通用选项列表 | 居中窗口、可滚动选项、独立说明区、搜索与返回按钮 | 原有返回值、热键、分类、禁用项、过滤和确认循环 |
| 确认与提示 | 说明滚动、选项按钮自动换行、默认焦点 | 原有默认“否”、按键过滤、取消与任意键语义 |
| 文字和数量输入 | 统一输入框、确认/取消按钮、长说明滚动 | 原有输入历史、回调、数量步进、取消返回值；保留等宽说明和返回输入焦点 |
| 通用物品单选器 | 物品列表与说明两栏，展示来源、操作参数和不可用原因 | 使用原 preset 的显示条件、过滤和拒绝原因；确认后返回真实 item_location，执行仍在调用方 |
| 仿生模块 | 主动/被动列表、能耗与详情、身体槽位、底部操作 | 原启停、燃料模式、外观、排序、改键和武器安装逻辑 |
| 变异与能力 | 主动/被动列表、说明、消耗和冷却、底部操作 | 原资源条件、启停、外观与改键逻辑 |
| 士气详情 | 可滚动列表，显示来源贡献、总值、疼痛、困倦和专注趋势 | 复用原版已计算的各行和值 |
| 其余原生 ImGui 窗口 | 共享生存菜单的暖黑半透明配色、白色正文、暖金色强调 | 保留各窗口已有内容和操作 |

通用选择覆盖等待、睡眠、物品用途、医疗等实际采用 uilist/query_popup 的入口；物品单选覆盖实际采用 inventory_pick_selector 且未开启拖放的入口。不能据此把所有名称相近的独立窗口都标成已适配。

只有原黑色文字映射为暖金色，白色正文及红绿等状态颜色保留。主题按 `view_3d` 与已有 3D 场景判定，独立于是否启用现代操作键；2D 和主菜单保持原主题。主题在窗口绘制前压栈，结束后恢复，不永久更改全局颜色。

具有自定义预览回调或指定布局的 uilist 保留原布局与回调，仅共享主题；这避免丢失预览和额外按键。物品单选器保留“完整物品选择 / 高级操作”入口，用于复杂筛选、内容层次与额外操作。原拖放、多选和弹药专用选择器未接入本批单选替代。

## 验证

- 窗口/单选专项：2 用例、209 断言通过。隐藏 SDL/OpenGL 窗口实际绘制 1280×720、1920×1080、640×480，检查滚动、禁用项、鼠标选择、数量确认、空列表、主题栈恢复、2D/3D 和操作模式独立性。
- 物品数据专项使用真实角色、背包、物品与原 preset，验证物品过滤、拒绝原因、参数字段及查看不消耗时间/AP、不改变 RNG。首次测试物品构造参数编译失败已修正，保留原日志。
- 功能回归：194 用例、17390 断言通过，含现有 FP3D、对话、随机数、原士气与仿生测试。
- 两套贴图与界面风格图形回归：3 用例、6468 断言通过。
- ENABLE_FP3D=ON/OFF 及测试构建通过。运行包：`runtime/modern-3d-simple-ui`，OFF 检查包：`runtime/simple-ui-off-check`。
- 证据在项目根目录 `qa/0i1/simple-ui-*`；布局截图在 `simple-ui-images`，已有完整图形回归截图在 `simple-ui-gl-images`。

上述绘制与点击专项覆盖共享窗口、输入和单选模型；没有将正式存档中所有仿生/变异能力的鼠标操作逐一游玩，也没有把所有物品用途的后续独立窗口标为已验证。

## 第二批

弹药选择、批量勾选、卸载选择、容器内容和独立物品详情使用生存菜单配色。弹药数量上限、批量选择、卸载目的地及确认仍交给原流程。对比选择保留勾选两件物品后进入对比的操作。打开详情或输入框时，下层窗口暂停接收点击。

车辆共用零件选择列表显示零件位置、损坏、余量和适用的故障说明。列表沿用原有候选项与快捷键，确认时复查可选条件。需要原有分类和详细数据时可进入“完整车辆列表”。

库存专项通过 2 个用例和 491 条断言。功能回归通过 212 个用例和 19051 条断言，图形和配色回归通过 3 个用例和 4966 条断言。车辆列表通过开启与关闭 3D 功能的编译检查，车辆实机菜单的完整操作链仍待验证。日志位于项目根目录的 `qa/0i1/simple-ui-selection-*`。

## 第三批

在 3D 中按 Tab 打开生存菜单，顶部可分别进入「变异」「仿生插件」「武术」。

- 变异页区分被动和主动变异，显示说明及启用状态。主动变异可在该页启停。
- 仿生插件页显示当前电量、启用消耗和说明。可在该页启停插件、安装或卸下兼容仿生武器、切换发电插件的节能档位。
- 武术页显示当前战斗方式，可切换可用武术、查看说明，以及设置保持双手空闲。

操作沿用角色的能力条件、资源消耗和效果。普通开关和武术切换完成后留在当前页。需要输入目标或选择武器等参数的能力会打开相应的操作窗口，开始耗时活动或需要回到场景时退出生存菜单。

车辆改装主窗口已增加简易布局，可查看安装位置、选中位置的零件和状态，以及进入安装、修理、拆除。保留完整车辆窗口入口，任务条件仍由车辆系统检查。

3D 和非 3D 构建均通过。3D 专项及功能回归通过 134 个用例和 14166 条断言，含三个能力页在 640×480、150% 缩放下的实际绘制。图形与配色回归通过 3 个用例和 6468 条断言，车辆回归通过 46 个用例和 503825 条断言。合并车辆与 3D 用例运行时，有三项场景快照测试出现额外精灵，两组分开运行均通过。需要指定目标的能力及车辆改装全流程尚未在正式存档中逐项验证。

运行包为 `runtime/modern-3d-ability-controls`。截图和日志位于项目根目录的 `qa/0i1/ability-controls-*`。
