# 3D 模式使用准星 + E 选取方向目标

日期：2026-11-08

## 用户操作

在第一人称 3D 模式中，执行需要指定相邻方向的动作时，不再弹出传统方向键选格界面。

1. 选择动作：例如按 Q 打开行动轮盘，选择“拖拽”；也可以从原版动作菜单执行打开、关闭、砸击或定向放下。
2. 游戏提示“等待目标”：用鼠标调整第一人称准星，对准相邻目标。
3. 按 E 确认目标。若没对准可触及目标或选到了不允许拖拽的生物，提示后继续等待下一次 E，而不会回退到方向窗口。
4. 按 Esc 可取消；切换 2D/3D 模式或返回主菜单也会清除待确认操作。
5. 长按 E 的目标交互轮盘现在对可拖拽的家具或车辆提供“拖拽 / 放开”选项，已识别准星目标则直接操作，不需要第二次选方向。

拖拽释放：已经拖住物体时再次执行“拖拽”可直接放开，仍保留原版行为。

## 覆盖操作

- 拖拽（ACTION_GRAB）
- 打开（ACTION_OPEN）
- 关闭（ACTION_CLOSE）
- 砸击（ACTION_SMASH，驾驶时保留原版手刹逻辑）
- 定向放下（ACTION_DIR_DROP）
- 查看（ACTION_EXAMINE / ACTION_EXAMINE_AND_PICKUP）
- 指定位置拾取（ACTION_PICKUP）
- 交谈（ACTION_CHAT）

这些动作仍调用 CDDA 原版操作逻辑。3D 新增的仅是**方向/对象选取方式**，不改变负重、拖拽阻力、车辆规则、攻击和物品操作的结果。

## 实现

- `src/fp3d_interaction.cpp/.h`：待确认动作状态；E 使用 `fp3d_compositor::interaction_target()` 得到准星命中的物体，由 `valid()` 检查相邻、视野、楼层、对象一致性；拖拽额外拒绝自身格、生物和无家具/车辆的位置。
- `src/handle_action.cpp`：截获 3D 中没有目标的五类方向动作，先等待 E；有目标的动作直接传位置给对应原版处理函数。`grab(target)` 与 `ACTION_DIR_DROP` 也支持传入已经验证过的地图位置。Esc 取消。
- `src/fp3d_quick_menu.cpp`：更新拖拽描述。
- `src/fp3d_compositor.cpp`：显示 HUD / 交互提示、模式变化和主菜单时清理选择状态。

## 实机回归建议

1. 走到椅子/桌子旁，Q → 拖拽 → 视角对准物体 → E，确认没有方向选择窗口。
2. 拖拽后再次触发 Q → 拖拽，确认放开。
3. 长按 E 指向可拖拽家具，选择“拖拽 / 放开”，确认无二次方向选择。
4. 准星瞄准远处、敌人或空气，按 E 应提示靠近/调整准星，不应操作错误对象。
5. 分别对门、车门、砸击对象执行 E 确认；先验证能在有效距离执行，远处不可触及。
6. 对待选择状态按 Esc 或切换 2D / 返回主菜单，应解除待确认动作。
7. 在原版 2D 模式检查旧方向交互保持不变。
