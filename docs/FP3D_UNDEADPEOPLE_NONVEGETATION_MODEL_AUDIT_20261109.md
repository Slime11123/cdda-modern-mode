# CDDA 3D：不死人贴图包非植被模型缺口（2026-11-09）

## 统计口径

本次是源码和本地 tileset JSON 的静态比较，不代表所有已实现模型已通过实机视觉验收。
植物和植物状自然地被不列入下一阶段专用立体建模目标：花草、树木、灌木、农作物、藻类、苔藓/地衣、真菌、海藻、盆栽和修剪树篱、部分异界植物状生长物。
海葵、海绵和形态无法确认是否为植物的异界有机体没有直接当作植被删掉，留待专门分类。

## 建议优先新建的非植被几何

P0：医疗/实验室设备，包括 f_autodoc、f_MRI、f_CTscan、f_IV_pole、f_dialysis、f_electron_microscope。
P1：工业设备，包括 f_diesel_generator、f_bandsaw、f_drill_press、f_heavy_lathe、f_hydraulic_press、f_forge。
P2：街景与室内设施，包括 f_dumpster、f_sign_stop、f_satellite、f_shower、f_gunsafe_c、f_safe_c。
P3：其他设施按复用部件和分层材质按批次制作；通用回退先保证未建模物体可见。

特殊：f_counter_gate_c 在 fp3d_furniture.cpp 中被显式阻断为柜台模型，不能因为没命中模型就直接重用咖啡桌形状。

## 说明与边界

- 被排除的植物仍然需要在 3D 中可见，优先采用当前贴图包相应图片的交叉 Billboard、低矮卡片、地表 Decal、植被随季节切换。
- 外星生物结构、海洋动物等非植物类自然物体未自动删去，避免错排。
- 这份清单仅包括 f_ 家具类 ID；建筑地形 t_ 已有通用几何，特殊地形的完整逐项模型缺口需另外统计。
- 2D 怪物、人物和普通物品按项目既定 2.5D 技术路线处理，不计入本次专用模型待办。
