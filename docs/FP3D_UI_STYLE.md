# UI 栏独立选择（2026-11-03）

入口：F6 → 4「UI 栏样式」，或选项 → 界面 → 侧栏界面选项 →「UI 栏样式」。

| 设置 | 2D 经典 / 2D 现代 | 3D |
| --- | --- | --- |
| 跟随模式（默认） | 原版侧栏 | 3D HUD |
| 原版侧栏 | 原版侧栏 | 原版侧栏 |
| 3D HUD | 3D HUD | 3D HUD |

F5 仍只切换操作/视角模式；UI 样式独立保存到 `FP3D_UI_STYLE` 用户选项。
F6 中选择后立即保存，取消不修改。通过选项页修改则沿用原版保存确认。
UI 选择只改变信息显示，HUD 中显示快捷栏不代表 2D 原版键位会被替换成 3D 键位。

原版侧栏保留原版布局、左右位置和面板配置；3D 合成仅覆盖地图范围。
2D HUD 使用独立状态采集，不为显示信息栏生成 3D 场景；2D 罗盘固定北向。
菜单期间隐藏 HUD，返回主菜单时清理状态，避免显示上次角色信息。

验证：

- 九种操作模式和 UI 样式组合：93 条断言通过，包含实际合成不覆盖原版右侧栏像素、左右侧栏空间、状态来源和菜单遮挡检查。
- 原有输入回归：9 用例 / 677 条断言通过。
- 隐藏窗口图形回归：2 用例 / 4658 条断言通过。

运行包：`runtime/modern-controls-ui-style`。两个 3D 启动器均指向此目录，重新启动生效。
