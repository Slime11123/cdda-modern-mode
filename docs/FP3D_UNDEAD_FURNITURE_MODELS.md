# CDDA 3D 不死人家具模型与分面贴图（第二批）

日期：2026-11-07。基础：CDDA 0.I-1 + Windows SDL2 / OpenGL `ENABLE_FP3D`。**仅在本地项目实现；没有上传外部不死人贴图包。**

## 取材规则（必须遵守）

- 参考本地 `assets/tilesets/MSX++UnDeadPeopleEdition/tile_config.json`、`normal_furniture.png` 与现有游戏 `tileset` 查找/继承机制，**不把贴图复制到 Git 仓库**。
- 不死人贴图包中的同一张 2D 图块可能同时描绘顶盖、正立面、阴影、脚架或从斜上方看的整个物体。只截取作为真实材质合理的像素，再分别指定 `top`、`front`、`side`；弃用假透视轮廓、贴图阴影及透明背景。
- 不把 2D 俯视床垫、桌面和台球绿呢直接铺到立面。钢琴、铁砧、锯床、窑炉等带明显伪 3D 轮廓的图块只取黑漆/金属/石砖/键盘等适用局部，物体结构由真实 3D 几何生成。
- 只有 `selected->get_tileset_id() == "UNDEAD_PEOPLE_BASE"` 时启用这一批专用 UV 裁剪；其他图块包仍使用其既有兼容/回退材质。

## 新增的真实 3D 几何

| 模型形态 | 覆盖的原版家具 ID（或同类变体） | 主要几何与取材 |
|---|---|---|
| 展示柜 `display_case` | `f_displaycase`、`f_displaycase_b` | 下柜体、上展示箱、顶板；分离抽屉立面与浅色展示区 |
| 文件柜 `file_cabinet` | `f_filing_cabinet` | 独立立柜与顶盖，抽屉纹理仅映射至正面 |
| 售货机 `vending_machine` | `f_vending_c`、`f_vending_o`、`f_vending_reinforced` | 主机与上檐；红色顶盖、商品/操作面板正面、窄金属侧面分别裁剪 |
| 工作台 `workbench` | `f_workbench` | 实体台面、四脚与横撑；顶面取俯视面板，支架用独立小块灰木材质 |
| 钢琴 `piano` | `f_piano` | 主琴箱、独立琴键台、顶盖与四脚；不使用 2D 琴身的斜透视形状 |
| 台球桌 `pool_table` | `f_pool_table` | 桌边、中心绿色台面、四条桌腿；绿呢仅用于水平面 |
| 铁砧 `anvil` | `f_anvil` | 底座、砧身、砧面、凸出砧角；使用铁灰局部，不贴整幅剪影 |
| 窑炉 `kiln` | `f_kiln_empty/full`、`f_kiln_metal_empty/full`、`f_kiln_portable_empty/full` | 近圆形炉体、上沿、炉口、底缘；火色仅在开口顶部 |
| 锯床 `table_saw` | `f_tablesaw` | 工作台、四脚和高出台面的独立锯刃；不将画出的锯刃阴影作为顶面 |
| 种植箱 `planter` | `f_planter` 和成熟/播种/幼苗/收获对应变体 | 木箱主体、土壤表面及四侧实体木沿；土壤仅在水平面 |

**同时改进既有贴图：** `f_table`、`f_desk`、`f_counter`、`f_bed` 的顶面与侧面分开处理；`f_bookcase` 的书本纹理改为正面而非把整张书本图用作侧面。

## 代码位置

- `src/fp3d_furniture.h`：追加 10 个几何形态枚举，保留原有枚举顺序。
- `src/fp3d_furniture.cpp`：按真实家具 ID 与 `looks_like` 查找形态；增加真实分块模型、物品摆放高度和有正面模型的朝向。
- `src/fp3d_materials.cpp`：基于不死人图块的 32×32 贴图槽进行分面裁剪；兼容变体贴图。
- `src/fp3d_scene.cpp`：新储物设施纳入已实现的邻接轴向判定；绘制仍经过现有静态几何缓存和分块提交。
- 本地参考拼图：`qa/undead_furniture_atlas_sheet.png`（仅用于审查，不添加到 Git）。

## 安全性与限制

- 不改 CDDA 原版地图、碰撞、物品、门、交互、建造或存档数据，仅替换 3D 视图的外观。
- 目前采用**单格家具的几何近似**，如台球桌、钢琴等大型家具未跨地图格建独立碰撞物体；不具备真实反射、透明玻璃和动画。
- 同一个游戏物件的美术特征可能随不死人贴图包版本改变；这些 UV 切片按当前本地版本实现，不应对其他版本/图块包承诺完全一致。
- 编译成功不等于所有材质已通过游戏截图验收；须实机检查抽屉正面、柜台上表面、售货机门面、钢琴键盘、台球桌绿呢和锯床锯刃。
- 原外部素材及衍生图不推送 GitHub，不打进公开发布包，遵守仓库 `AGENTS.md` 的版权与发布约束。

## 测试建议

1. 在游戏设置中启用 **UNDEAD_PEOPLE_BASE** 并切换 3D，进入有展示柜/办公文件柜/工作台的室内场景。
2. 从正面、侧面和俯视角度观察，确认立面不再是完整的 2D 假透视图、顶面没有抽屉/把手纹理。
3. 查看同一排柜子的转角与末端，检查旋转、纹理方向和相邻家具的遮挡。
4. 检查地面/楼层变换与多个家具同屏时渲染不闪烁；切回 2D 应保留原版玩法。
