# 移动绘制优化与城市远景

日期：2026-10-28。基线 `711f7bae`。交付目录 `runtime/city-perf`。

## 改动

用户反馈移动卡顿、远处没有城市。实机日志显示每次快照采集约 4–6 ms，场景包含约 14000 个记忆地形格、1600 个远景块。此前绘制每帧重建地图索引及分组、计算所有可见区域签名、遍历材质需求，并逐远景块提交几何；即使游戏状态未改变也重复进行这些操作。仅凭这些日志不能断言整次行动卡顿都来自采集。

本次优化：

- 为每份已发布场景分配渲染代号。地图索引、几何分组和邻接签名在场景变化时更新；转头及移动插值帧复用现有数据。材质需求也仅在新场景或材质重置时遍历。
- 远景改为 48×48 格分区缓存。走动时复用未变化分区，边界裁切或建筑变化只刷新相关分区；切换图块、季节或释放 GL 资源会正确失效。避免每帧逐块绘制约 1600 个地表块及其树卡片。
- 当当前地图视口被完整 3D 场景覆盖时，省去下方不可见的 11 层原版 2D 精灵绘制。原版视野准备和完整探索记忆更新继续执行。2D 模式、背包等菜单、观察其他中心位置时保留原绘制路径；F5 和菜单状态切换会通知原版主界面重绘。

城市远景：

- 原先大地图建筑类型全部落入普通草地回退，本次加入住宅、商业、工业及公共建筑等简化墙体和屋顶轮廓，使用现有图块材质。
- 地表与林地保持约 240 格范围，额外城市轮廓延伸至约 960 格；远平面为 1536，镜头仍为 120°。
- 建筑位置来自现有大地图类型；根据用途分配 3–9 米的示意高度。它们是远处城市轮廓，不是实际房屋室内或精确楼层复原，接近后由真实地图替代。
- 沿用白天/室外可见门槛。不会生成新的地图或扩大原版怪物、物品和游戏模拟范围，也不依赖先在 2D 探索。没有现成大地图数据的地方继续显示天空。

## 验证与性能范围

- 功能回归：34 用例、1164 项断言通过，退出码 0。包含原版视野、移动、上下楼、地面物品，以及 720 格外商业建筑轮廓采集与随机数保持。
- 实际隐藏窗口 OpenGL：1472 项断言通过，退出码 0，两套图块为 UndeadPeople 和 RetroDays。验证 720 格外建筑确实改变画面、缓存重复帧不重新索引、移动复用远景、单处高度变化只重建一个分区；已有窗口、天空、遮挡、F5 与菜单检查通过。
- 额外调用真实 `cata_tiles::draw`，对比普通绘制及 3D 覆盖路径，确认清除记忆后墙体与家具仍能重新写入相同探索记忆，两套图块均通过。
- 同机约 14600–14700 格场景中，未变化帧的 3D CPU 绘制提交从上一版约 1.44–1.46 ms 降至本次约 0.06–0.07 ms。此数字不包含整个游戏行动、世界更新、快照准备或 GPU 完成时间，不能当作实机整帧 FPS。
- 本次首次生成完整场景缓存仍约 16–23 ms；自然地图新区域加载、原版回合模拟等仍可能产生停顿，未宣称所有卡顿已消除。已打包新版供原存档继续游玩验证。
- Feature ON 游戏构建与打包通过，代码格式及差异检查通过。本次未重跑 Feature OFF 全量构建，原版绘制分支仍由编译开关及运行状态保护。

记录（相对项目根目录）：`qa/0i1/city-perf-cpu.log`、`city-perf-gl.log`、`city-perf-build.log`；绘制基准表与合成图在 `qa/0i1/city-perf-gl/`。合成测试图不是用户存档截图。

## 使用

根目录 `启动3D技术验证.cmd` 指向 `runtime/city-perf`，沿用 `runtime/0i1/user` 中原有中文、不死人图块、按键和存档。保存退出当前游戏后重新运行启动器生效。当前旧进程和玩家存档未被修改。
