## 实现边界

- `fp3d_camera` 将 yaw 与 WASD 映射到八方向格子步长，再调用原版 `get_movement_action_from_delta(..., iso_rotate::yes)`。结果经原版输入上下文和 `game::handle_action` 结算，没有直接修改玩家位置、行动点或时间。
- 使用 SDL 原有单事件输入槽，不维护移动队列；普通按键重复仍由 SDL/原版循环处理。修饰键组合不被 WASD 重映射。
- 相机跟随只接收快照中的已确认坐标。相邻移动使用最多 100ms 的显示插值；只有原版确认且方向相符的正常步行允许平滑；受阻、改向、单格强制位移、较大位移、载具/骑乘移动、楼层变化及切换视角重置直接对齐。转头、刷新帧不驱动世界模拟。
- 第一人称投影为 65 度垂直视角，眼高 1.6 格。原版地图实际绘制区域用于计算合成范围，保留侧栏位置；FBO 尺寸随该区域调整，稳定尺寸下不重复分配。
- 仅在聚焦且收集正常游戏输入时启用相对鼠标。菜单、F5 关闭、失焦及退出释放；菜单保留原版文字输入。第一人称中的鼠标点击暂不触发底层 2D 寻路，交互属 P5。
- 游戏输入使用原生按键码，丢弃迟到的文本/组合消息；优先保留明确的按键码绑定，并兼容简单 ASCII 字符快捷键。中文文本输入仍交还原版菜单。
