# 角色比例、植物与宽视角调整

2026-10-27，按用户三项反馈完成以下修订。

1. NPC / 怪物等精灵的图集已按原素材比例装入方形槽，原绘制又把平面宽度压为高度的一半，造成额外的横向压缩。现改为方形绘制面，保持图集内原始宽高比，并扩大相应裁剪包围球，避免侧边过早消失。生物大小分类与原版感知规则保持。本项修复素材的显示比例，不重画图块包自身的人物造型。
2. 普通草地 `t_grass` 和低矮枯草 `t_grass_dead` 仅绘制地面，不再生成交叉草叶，也不申请植物图集槽。每格移除原有 14 个草叶三角形；长草、花和树木继续使用交叉面。灌木高度从 0.9 提升至 1.2 米，宽度也从 0.9 提升至 1.2 米，裁剪边界同步更新；树木尺寸保持。
3. 水平视角从 100° 提升至 120°，同距离的横向投影范围扩大约 45%。场景继续覆盖原版加载的 60 格半径及 96 米远平面，已检查没有残留的 12 格截断。本项扩大镜头覆盖范围，原版黑暗、墙体和生物感知仍决定可见内容。
