# 3D 暗处物体显示

2026-11-02：3D 视线范围内的实时地形、家具、物品和生物不再因光照不足而被过滤。此规则取代旧视距报告中“夜间遵守原版可见规则”的 3D 显示约定。

`fp3d_snapshot::capture` 保留原生视线缓存、遮挡、视距、楼层范围和失明检查，移除亮度阈值。外墙补充射线同样不依赖亮度。生物通过 `Creature::sees` 的显式三参数显示专用入口跳过位置亮度检查，继续检查隐形、藏匿、伪装、水下状态和姿态遮挡；两参数原版入口行为不变。

2D 显示、AI 感知、角色属性、地图记忆和原版互动条件不变；容器内不可见物品仍不显示。该改动只影响场景显示，不授予角色夜视能力，也不生成视距外地图。

回归覆盖夜间 25 格地形、15 格家具/物品/怪物、夜间上层墙面，以及墙后物体、隐形怪物、失明、过期缓存和只读状态。验证日志位于项目 `qa/dark-visibility/`。

验证结果：完整 `[fp3d]` 功能回归 118 用例 / 9961 断言通过（`cpu-final.log`）；原版白天、室内、无光、墙体遮挡和月光五用例 / 1552 断言通过（`native.log`）；真实隐藏 OpenGL 图形回归 1 用例 / 4181 断言通过（`gl-active.log`）。游戏及测试编译完成，运行包 `runtime/dark-visibility` 的启动检查退出 0。首次图形检查缺少测试目录图块包，第二次未设置默认进入 3D 的环境变量，两次配置失败记录保留；补齐配置后通过。

两个 3D 启动器已切换到该运行包，继续使用 `runtime/0i1/user`；保存退出重开生效。未进行正式存档的人工夜间游玩验收。验证及运行包包含当时工作树中其他任务的现有改动，没有回滚这些改动。
