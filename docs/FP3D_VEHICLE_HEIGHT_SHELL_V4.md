# CDDA 0.I-1 / FP3D 汽车车身与高度 V4 实机反馈修复

日期：2026-11-08。依据用户新提供的 3D 实机截图及前两次「2D 完整红色汽车 vs 3D 方块框架」对照图，继续修复车辆视觉，不修改 CDDA 原版车辆数据和玩法。

## 发现的实际问题

1. **车太矮**：上一轮封闭轿车的 `roof` 仅绘到约 1.40 个 3D 世界单位，人物视点高度通常明显高于车顶，导致整体像压扁在地面的方盒。
2. **车型有时重新散架**：旧 `fp3d_snapshot.cpp` 对**每一个车零件**直接用原版 2D LOS 过滤。完整车辆从外面观察时，背面的围板/车门/车顶会因为**车辆自己的遮挡**而被过滤，不是原版车辆真的缺这些部件。旧 `build_shell()` 又要求至少两块车顶，导致轻微破损/侧面遮挡就退化为零散框架。
3. **车轮被侧板挡住**：上一版连续侧围沿原版挂点的外边缘布置，但轮胎中心仍在原来的挂点附近，金属围板与轮胎前后重叠，造成轮胎不清晰、车体贴地和车身像整块箱体。
4. **过多内部储物模块**：闭合车身中的 `CARGO` 装备仍可能叠加到机舱盖/车顶外，继续产生脱离车体的独立方盒。

## V4 已经修改的源代码

- `src/fp3d_vehicle_renderer.cpp`：为封闭式车辆增加 `enclosed_cab_vertical_scale = 1.36f`。从源模型 `1.40` 的车顶高度提高到 `1.904` 世界单位；完整门框、座椅、车窗、机舱盖和车顶按相同 Y 比例缩放。车体局部 `mount_x/mount_y` 位置、底层碰撞逻辑与世界 XY 不变。
- 轮子单独保留真实**圆形**几何，不参与 Y 轴缩放（避免变成椭圆）；普通轮胎直径约 `0.90` 世界单位，轻型窄胎约 `0.68`，损坏胎约 `0.56`。
- 轮胎外侧中心从 `0.22` 适当调整为 `0.50`（相对于最外侧挂点的本地横向偏移），保持轮胎外侧面可见。侧围添加车轮挂点对应的**轮拱开口**，仅保留轮拱上沿和左右窄边，而不是拿全高金属板盖住轮子。该处理只用于轮胎所在的车身侧面。
- 透明玻璃在独立 alpha pass 绘制，也施加**完全相同**的 1.36 倍本地 Y 轴缩放，防止玻璃与门框对不齐。它仍在建筑和人物的不透明场景绘制之后完成。
- `build_shell` 识别条件从 `frame>=5 && roof>=2 && edges>=3` 改为 `frame>=5 && edges>=3 && (roof>=1 || (doors>=2 && windows>=1))`。有驾驶舱轮廓但失去部分屋顶的损坏车不再退回裸车架；单车、手推车仍不会被强制套封闭轿车车壳。
- `src/fp3d_snapshot.cpp`：改用**实体级可见性门槛**：只要整辆车有至少一处原版真实挂点处于玩家已知且可见范围，便按真实安装挂点复制完整车体部件快照。3D 的实际房屋/地物由 OpenGL 深度缓冲遮挡，避免把车后侧零件错误当作不存在。不再复制指针到渲染线程。
- 对于闭合车身下的 `CARGO` 储物物件，不再把它当作外部方盒绘制；开放车体仍保留可见储物模块。

本版仍沿用 V3 的 `DOOR+WINDOW` 正确分类、从玩家选中的图块包采样车漆颜色、倾斜挡风玻璃、损坏侧板和独立车门铰链。未改动 `vehicle.cpp`、`map.cpp`、驾驶输入或存档结构。
