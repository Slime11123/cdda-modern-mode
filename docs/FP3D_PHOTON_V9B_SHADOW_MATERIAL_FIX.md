# CDDA 3D Photon v9b — 车辆阴影灰色矩形修复与材质反射升级

日期：2026-11-08（本机开发验证）

## 用户视觉参考

- 图 1：靠近红色车辆时，车身周围的路面出现大块亮灰色近矩形区域，像是光照被画成一块灰色贴图。
- 图 2：以前的道路/路灯与车辆在阳光下有更自然的明暗层次，阴影为深色而非灰白。
- 两张截图视角不同，不可简单用相同像素位置断言阴影轮廓相同。QA 必须明确同场景、同视角时才算 A/B。

## 根因与已改源码

1. `src/fp3d_shaderpacks.cpp` 的原生太阳阴影着色器先根据 3x3 PCF 减少日照，随后 `color += vec3(0.088,0.097,0.110)*indirect_day` 为所有阴影物体添加固定的蓝灰色。对于原本很暗的沥青，这可能把受阴影影响区域变得**比不受阴影区域还亮**，视觉上像灰色矩形。已移除这段与物体材质无关的蓝灰叠加；原本在 `fp3d_scene.cpp` 中按日照提供的稳定环境光负责室内间接亮度，阴影后处理只扣除太阳直射，不为物体刷灰色。
2. 只为排查全局雾气而临时调整的固定 GL_FOG、Photon 雾浓度以及湿地灰色基调已经**撤回**，保留原来熟悉的天空与路面色调。该项判断是用户指正后的修订：主要问题是图 1 的异常车影，不是所有天气都应该减少雾。
3. 下一阶段的材料光学基础在 `fp3d_scene.cpp`、`fp3d_mcshader.cpp` 中做了增量开发：原生已可见地形的独立反射材质纹理现用 R=反射率、G=粗糙度、B=微法线强度。水面较光滑，混凝土较粗糙，湿沥青居中；世界空间固定的微法线会随水波而变化但不会因为镜头旋转产生贴屏闪烁。反射的 Fresnel 近似、不同材质模糊范围和反射强度不再完全相同。
4. 保留此前增强的家具/路灯/邮箱真实阴影几何和实际可见车辆同一套不透明车壳网格，不修改车辆碰撞及 2D 功能。当前仍是一张近场太阳阴影贴图，**并未完成真正的级联阴影（CSM）或时域 SSR 重投影**。

## 验证

- Windows UCRT64 `ENABLE_FP3D=ON` CMake 配置、全量增量编译及最终链接 EXIT=0。
- OpenGL 4.6 / NVIDIA Photon GLSL 回归：60 次 FBO resize、HDR、太阳深度阴影、光照关闭回退、简易 MC final、体积光/水面与湿路 SSR 均 PASS。方向阴影 synthetic 对照 red-channel 由约 204 降至 161；阴影遮挡时的体积光累计零。水/湿路在有材质遮罩时可反射，干路纹理误反射差值 0。
- 真正 3D `ShaderDaylightLab`（2520×1392）加载 Photon v1.4，4 辆车/156 车辆部件/30 家具投影体，太阳阴影 FBO 非零，OpenGL 读回错误 0。v7b 与 v9b 同视角、同世界实际 FBO 的道路 ROI 平均 RGB 比较：原版约 (100.283,105.386,102.934)，新约 (99.603,104.527,101.833)；改动消除了硬编码蓝灰补光，但保留方向阴影。截图 `qa/car-shadow-v7b_original_shadow.png`、`qa/car-shadow-v9b_original_atmosphere_shadow.png`。
- `qa/car-shadow-v9b_no_shadow.png` 是诊断专用关闭太阳贴图的对照（不会改用户运行配置），用于验证太阳阴影开关通路，而不是推荐使用无阴影模式。
- **当前测试摄像机没有靠近用户图 1 那辆红车**，不能据此宣称图 1 的矩形阴影几何轮廓已经经过实机验证。建议用户进入那辆车旁相同角度复查，随后利用同位置截图定位可能的模型/屋顶投影几何残留。
