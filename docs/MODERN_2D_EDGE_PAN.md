# 2D 现代模式：鼠标边缘平滑观察

2026-11-03

- 仅在 2D 现代模式的世界操作界面生效，无需按住鼠标按键。
- 鼠标离开地图中心的圆形静止区后，视角沿人物到鼠标的方向连续平滑偏移；360° 任意角度均可探看，不需要移动到矩形屏幕边缘或固定方向。
- 鼠标返回中央或进入右侧栏时，视角平滑回正。离开窗口、失焦、打开菜单或切换模式时清除偏移。
- **视野最广、人物最小的缩放档（原版 zoom=4）禁用并清除偏移。**
- 以地图短边一半为参考半径：内部 55% 为静止区，其外按鼠标到中心的距离逐渐增大偏移，在参考圆周处达到上限。最大偏移半径为地图短边的 45%，横纵轴使用相同的像素尺度，极限轨迹是圆而非椭圆或矩形。采用与刷新率无关的缓动。
- 仅改变图块绘制位置和鼠标选格换算，不改变人物位置、原版 view_offset、游戏时间或视野判定。隐藏区域仍受原版光照、遮挡、地图记忆及地图加载范围约束。
- 原版正交和等距图块均按屏幕方向偏移；同步调整绘制覆盖范围，并裁切偏移后的文字/色块，避免越过地图窗口。
