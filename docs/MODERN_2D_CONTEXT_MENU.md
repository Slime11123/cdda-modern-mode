# 2D 现代模式：右键情境菜单与 Q 行动轮盘

2026-11-03

## 操作

- 在地图上右键点击当前可见的地块、家具、地面物品或人物，在鼠标位置打开列表；靠近窗口边缘时自动向内收拢。
- 首项固定为 **前往此处**，使用原版 `safe_route_to` 和逐步自动移动，不瞬移。当前位置、被占据或不可进入的目标会禁用此项；危险和障碍仍由原版处理。
- 其余项目随目标变化：打开/关闭、拾取物品、查看/搜索、砸毁、交谈、近战攻击、队友守卫/跟随、上楼/下楼。超出触及距离的操作显示为禁用，楼梯要求站在目标格。隐藏人物不会作为人物选项泄露。
- 操作说明及禁用原因固定显示在菜单底部，不再使用跟随鼠标的浮动提示框。可用选项在左键按下时响应。
- 点击菜单项执行；上下键和 Enter 也可选择。Esc、再按右键或点击菜单外取消，不提交等待动作。
- **Q** 打开现有快捷行动轮盘：投掷、拖拽、变异能力、仿生装置、装填、附近物品、生存面板、更多行动。Esc、右键或再次按 Q 返回；鼠标或方向键/Enter 选择。
- Q 可在 F6 的 2D 现代配置中独立改键；2D 经典右键操作与 3D 操作配置保持原有行为。

## 与现有功能配合

- 右键选格先经过当前圆形移镜的坐标换算，再固定为世界目标；菜单打开期间冻结移镜，避免目标在菜单下方滑动或回正。
- 所有实际操作均在原版动作分派边界处理；模型和绘图回调只生成/选择请求。执行前重新检查可见性、目标状态、触及距离和相关条件。
- 近战沿用已有非敌对确认和原版安全模式；拾取复用现有单件快捡/多件目标物品面板；交谈、开关门、搜索和楼层移动仍使用原版执行链。
- Q 轮盘可在没有 3D 场景快照时使用。2D 背景在 GPU 内复制以避免透明轮盘反复叠加残影；关闭后恢复原地图。
- 保留 Tab 综合生存面板、圆形 360° 探看以及最广视野档禁用移镜的规则。
