# CDDA 3D Raymarch v3 — 反射、独立材质遮罩、阴影遮挡体积太阳光

更新：2026-11-08。本功能属于 CDDA 的复杂 Minecraft/Photon 光影视觉桥，并非运行原版 Iris/Photon 全部渲染程序。

## 已实现
- 原有 3D HDR 颜色、可采样深度及近场太阳阴影图作为输入；世界空间逆变换使用同一帧真实摄像机高度，而不是固定 1.6 米。
- 屏幕空间 SSR：GLSL 120 从相邻深度重建可见面法线，反射视线后沿屏幕场景深度至多 16 步查找交点、屏幕原色。有限厚度匹配、菲涅尔强度与边界衰减防止乱反射。不能凭空显示屏幕外、原版不可见的场景。
- 独立地形反射材质 FBO：新增 RGBA8 色彩 attachment 与原场景共享深度，深度测试开启但深度写入禁用。使用已许可显示的原生地形类别绘制材料标记（路面、沥青、铺装、侧道、混凝土仅下雨时；水面和污水晴天也可反射），车身/屋顶遮挡仍由原深度缓冲约束。驱动不支持新 FBO 时单独关闭 SSR，不中断游戏。
- 阴影遮挡体积太阳光：沿世界空间视线 8 次采样太阳方向深度图，并计算光照遮挡和有限距离透射损失，区别于旧的屏幕中心太阳光束；完全被遮挡的测试场景体积亮度增量为零。
- F5/F6 → 光影包增加两项独立控制：水面与雨天湿地 SSR 反射、阴影遮挡体积太阳光。默认开启，存储在同一光影包目录 .wet_ssr / .shadow_volume，仅极高画质和复杂 Minecraft 视觉适配桥执行。不会改变 2D、简易 final.fsh 或原版战斗/寻路/车辆数据。

## 测试与证据
- Windows UCRT64 完整 ENABLE_FP3D ON 构建和链接 exit=0；独立 shaderpack_gl_smoke OpenGL 检查含 60 次 FBO 尺寸回归、原生阴影、简单 Minecraft final、Photon、GLSL 失败回退，通过。
- 真正 OpenGL 2.1 编译执行 raymarch 片元：无阻挡体积光平均 RGB 改变约 4.895；反射材质遮罩下 6032 个湿表面像素改变；晴天水面同样有反射；未标记材料最大偏差为 1；完整阻挡太阳纹理后体积光差异为零。
- 真正 CDDA 3D ShaderDaylightLab 画面 Photon v1.4 正常加载：2520×1392，4 辆车辆、156 个可见车辆部件，真实太阳阴影图有效、新材质 FBO 有效、GL 读回错误为零。干燥真实场景截屏 qa/raymarch-v3-photon-real-frame.png，其中材质像素为零是因为没有可见的湿路面和水面。
- 同一原版地图和四辆车辆，在仅本机隔离 QA 抓帧期间设置 CDDA_FP3D_CAPTURE_FRAME=1 与 CDDA_FP3D_QA_FORCE_WET=1：真实可见路面遮罩像素 1,407,887，反射 FBO 错误 0、GL 错误 0，路灯/建筑可在湿路面出现屏幕空间反射。实机截图 qa/raymarch-v3-photon-wet-qa.png。此选项不会改变 CDDA 天气模拟或存档，测试后偏好还原。
- RTX 4080 SUPER 1080p 光影后处理独立 glFinish 基准约 0.2–0.4 毫秒/次，取决于场景材料以及 GPU 当前状态；不包含 3D 场景渲染、独立反射材质 Pass、太阳阴影贴图生成及全部游戏开销，不代表游戏整体帧率。
- 18 项新管线静态守护测试和 16 项原车辆阴影一致性检查通过；新版 EXE 的 --jsonverify 返回 0，启动脚本语法通过。

## 还没有完成
- 这是屏幕空间光线步进，不是离屏/硬件光追；没有每个物体的 PBR 法线、粗糙度、MRT 动态材质、完整 GI 或时域累积。
- 原版 Iris/Photon 的多阶段 composite/deferred/gbuffers、原版体积云、水面法线波纹、精确雨夜反射、高低太阳角度多级级联阴影尚未实现。
- 夜间、各种天气、多层建筑、旋转驾驶车辆及整体帧率需继续真实游戏验收；扩展更多 mod 地面材质 ID 也需要后续工作。

新独立程序为 runtime/modern-3d-shaderpacks/cataclysm-tiles-raymarch-v3.exe，原启动3D操作修复验证.cmd 已指向新版；原 exe 和玩家存档不改动。没有 Git 提交或上传第三方 Photon ZIP。
