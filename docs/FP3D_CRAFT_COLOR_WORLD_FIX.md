# 生存菜单原版彩色文字与 3D 家具 / 楼层修复记录

更新日期：2026-11-06。基于 CDDA 0.I-1 / ENABLE_FP3D。仅对当前本地源码和独立测试版生效，未提交、未推送 GitHub。

## 一、制作、建造彩色文字

- `src/fp3d_crafting.cpp`：配方说明不再调用 `remove_color_tags`；材料、工具采用 `requirement_data::get_folded_tools_list` 和 `get_folded_components_list`，根据当前制作物品清单计算满足与缺失，保留原版颜色标签。
- `src/fp3d_construction.cpp`：各阶段的材料、工具用对应原版接口生成彩色条目；满足显示绿色、不满足显示红色。
- `src/fp3d_modern_ui.cpp`：右侧制作及建造说明由普通 `ImGui::TextWrapped` 改为 `cataimgui::draw_colored_text`，继承 CDDA 支持的原版颜色与文本折行。
- 仍由原版处理材料替代、正式制作建造许可、用时、技能、光照与其他逻辑；纯 UI 阅读不耗回合。

## 二、家具朝向

- `src/fp3d_scene.cpp`：根据同类家具或相关柜台/储物设施在东西或南北方向的毗邻关系推断整排主轴，优先选择与该主轴相容的墙面作为背面。避免一排柜子的端头仅因为贴着侧墙便转 90°。
- `src/fp3d_furniture.cpp`：普通长凳也参与靠墙方向推断；原先仅特定有正面家具参与。
- 注意：原版家具数据未逐件保存玩家可编辑的朝向，修正属于渲染推断，对复杂独立家具摆法仍可能需要后续按具体家具类型细化。

## 三、上下楼后地板闪烁

- `src/fp3d_scene.cpp`：楼梯 `GOES_DOWN` 开口在下层不可见/未捕获时仍保持开口，不再由于缺少下层的配对楼梯单元而补绘地板。
- `src/fp3d_camera.h`：透视近裁剪面从 0.05 调整到 0.20；当前 FBO 是 24 位深度、远裁剪面约 1536，缩小深度范围有助于提高地板附近的深度排序精度。
- 不通过盲目叠加共面楼板或全局禁用深度测试掩盖问题；楼板与天花板重复面仍需在出现特定地图复现时继续检查。

## 构建与验证

- 使用项目既有 CMake/Ninja `cataclysm-tiles` 配置构建成功（BUILD_EXIT=0）。
- 新版可执行文件在 `runtime/modern-bestiary/cataclysm-tiles.exe`，无修改原来的 `runtime/modern-3d-climbing-models`。
- `--help` 启动检查：退出 0，stderr 为空。
- 指定正确 `--basepath` 后 `--jsonverify`：退出 0；部分测试日志提示字体文件路径，但属于非致命警告。
- 启动测试：双击工程根目录 `启动综合修复验证.cmd`。
