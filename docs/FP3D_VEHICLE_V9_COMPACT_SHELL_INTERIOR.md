# CDDA FP3D：V9 小型封闭车辆车壳与座椅重构

日期：2026-11-08。参考用户最新截图：图 1 为 3D 车内，出现粗红色立面、占用大量视野的黑色座椅和木纹坐垫；图 2 为 3D 外侧，整侧被夸张红色实心壳板堵住且前后壳接缝明显；图 3 是原版 2D 俯视图，车辆为纵向紧凑布局。**V9 已直接修改本地正式源码并编译为独立 EXE，但仍需用户回到该场景进行画面验收。**

## 根因定位

- 原版 `data/json/vehicles/cars.json` 里的 `Supercompact Tandem Car`、`Supercompact Car`、`Microcar` 等紧凑车，其实际侧边装了 `door` 与 `halfboard`，但没有单独名叫 `window` 的部件。以前的 `draw_closed_silhouette()` 把「这一格没有显式窗户」判断为必须补一整块从腰线到车顶的**不透明车漆板**。因此用户在 3D 看到的不是一个窗框，而是挡住座舱的巨大红墙。
- 原本车顶高 1.42 本地单位并整体乘以 1.36，原来的车门腰线位置却高达 .92×1.36≈1.25 世界单位，半隔板和普通车门没有区别，视觉上遮挡过多。
- `cabin_seat()` 的坐垫与靠背太宽、太高；它还把原版俯视 2D 图块铺到坐垫上，形成用户图里如木板般的假纹理。
- 有些车型没有独立原生后挡玻璃，旧算法为补漏直接生成高大的、不透明的红色斜后围，阻断座舱。

## V9 已实现的源码修复

唯一修改的生产代码：
- `src/fp3d_vehicle_renderer.cpp`
- `src/fp3d_targeting.cpp`

| 目标 | 变化 | 原版行为 |
|---|---|---|
| 半隔板 | `shell_cell.halfboard` 精确标记 `part.id` 含 `halfboard` 的零件，半隔板只画 `0.31~0.59` 本地高度的真实低围板，位置仍依赖原版 `part.mount` | 不把半隔板伸到玻璃/车顶，也不凭空恢复损坏侧板 |
| 普通车门外壳 | 封闭的真正车门外皮只到 `.82` 腰线（之前 `.92`），上半部保留窗洞；打开车门不画重复闭合侧板 | 门开合、门锁、碰撞和行动消耗继续用原版 CDDA |
| 上半部大红面 | 完全移除「没有 WINDOW 则生成完整红色上半板」分支；用约 `.042` 宽的 A/B/C 立柱与上下腰线代替 | 真正开门、损坏门窗仍留缺口 |
| 前后与车顶连接 | 小型车后部没有原生玻璃时，不再生成整个实心斜后围，而是按车身外侧及车顶角点生成细 C 柱和收口线 | 皮卡车厢仍保持露天 |
| 3D 视觉玻璃 | 对具有完整原生挡风玻璃、闭合未损坏的门/低侧围的原版封闭小车，即使其 0.I JSON 未定义独立 WINDOW 部件，也用半透明面实现**视觉推断玻璃**；后部同时具备至少两个完好安装支撑才生成后玻璃 | 只影响渲染，不增加任何原生玻璃零件、碰撞或视线权限；若原生窗被明确打碎，则不额外补全 |
| 车内座椅 | 坐垫约 `.59×.61`，本地高 `.46~.58`；靠背局部尺寸约 `.105×.60`，至 `1.00`；独立支架/小侧垫；没有 2D 图块伪立体纹理 | 一个真实原生 `SEAT` 安装格绘制一个座椅，方向按车体前方 +X，换座仍服从 CDDA |
| 准星拾取 | 同步调小关门与座椅在 `fp3d_targeting.cpp` 的拾取盒：闭合门不再在玻璃孔洞高度挡住射线，座椅拾取盒覆盖新尺寸 | P3-B 原版 E 操作、合法距离及零件身份复核继续保留 |

## 实际本地构建和 QA

- 脚本：`qa/apply_vehicle_v9_compact_shell_seats.py`、`qa/validate_vehicle_v9_compact_shell.py`；结果 `qa/vehicle-v9-compact-shell-validation.json`。
- 验证 0.I-1 的 `Supercompact Tandem Car`、`Supercompact Car`、`Microcar`、`4x4 Car` 和 `Station Wagon` 原版 2D 安装格。双座超紧凑车有 2 个 `halfboard`、2 个 `door`，没有额外的 `window`，符合已定位的旧算法症状。
- 24 个离散原生转向角及多个座椅安装点的刚性正逆旋转误差小于浮点容许值。
- Windows CMake/Ninja 构建目标 `cataclysm-tiles` 全部成功，链接退出码 0；单独游戏启动 `--help`、CDDA `--jsonverify` 的日志见 `qa/vehicle-v9-*.log`。
- 独立测试包：`runtime/modern-vehicle-shell-interior-v9/cataclysm-tiles.exe`，共 49 个 DLL 使用旧版本硬链接，不再重复拷贝造成额外磁盘占用。
- 测试启动文件：外层工作区 `启动车辆3D车壳与内饰修复V9.cmd` / `Start-VehicleShellInterior-V9.cmd`。旧 P3-B、工作台颜色修复和主光影测试启动器均保留。

## 尚未完成的验收与后续

**没有在用户最新截图的同一辆车上进行实际 V9 画面验收，因此不能声称上述外观问题已经完全解决。** 建议在 V9 中对同一辆车做 3D 正面、侧面、车内以及 2D 俯视对比，确认车门与半隔板是否正确分层、玻璃是否真正贴合车框、座椅比例是否更协调、前后 C 柱和车顶缝隙是否仍有问题。

此版依然是原版零件安装格驱动的低多边形程序化模型，而非为每种车型单独建好的高精度静态 3D 车模。多种改装车型、打开车门的精准铰链碰撞盒、严重事故破损车壳、乘车时第一人称隐藏近裁剪面以及 P4 性能回归仍需继续测试。不会为修补视觉模型而绕开原版 CDDA 模拟。

没有 Git 提交、push、Release，也没有修改玩家存档、基础车辆 JSON、第三方图块包或其他 Agent 当前修改的光影/家具源码。
