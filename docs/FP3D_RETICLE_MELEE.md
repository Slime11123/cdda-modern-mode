# 3D 准星攻击、砸击与手持挥击

2026-11-01。鼠标左键现在明确对准星射线命中的目标近战或砸击，不再借移动行为打开友好 NPC 菜单。

## 操作

- 左键点击可见、同层、一格内的生物：使用当前手持物品进行原版近战；空手则使用原版徒手攻击。不会走进目标格，也不会推开友好生物。
- 左键点击门窗、墙、家具、地面物品等表面：把准星命中格直接交给原版砸击，不再额外选择方向；可以按住继续砸。原版不可破坏的物体不会被强行破坏。
- 中立、友好 NPC 以及非敌对生物：先显示防误攻击窗口，默认选择“否”，可鼠标选择或按 Esc 取消。打开与关闭确认时均清除长按状态，确认后重新校验人物身份、位置与可见性；取消不攻击、不移动、不消耗行动点或随机数。
- 左键始终为近战／砸击，包括手持枪械时。右键继续进入原版瞄准／射击流程；枪械射击、弹药和装填结算保持原版。
- 超距、跨层、不可见、死亡或失效目标拒绝提交。驾驶时先退出车辆控制。

## 动画与结算

手持贴图从右下方向准星前方挥出，约 90 毫秒到达峰值，再在 210 毫秒内收回。动画以第一次实际绘制为起点，避免被原版战斗及世界更新耗时吞掉。没有手持物品时不会绘制虚构物品。

动画仅改变显示位置、角度和大小，不计算伤害，也不推进游戏时间。原版拒绝攻击、取消确认、砸击无效时不播放。进入菜单、失焦、切换 2D 或释放渲染器时清除动画。

生物伤害、行动点、武器磨损、耐力、特殊攻击及 NPC 被攻击后的反应均调用原版近战。明确攻击绕过移动方向随机偏转，眩晕时也不会因左键意外走到另一格或攻击无关目标。砸击保留原版派系财产警告、车辆盗窃判断、尸体捣碎及活动规则；定点长按不额外弹出“持续砸至破坏”询问。
