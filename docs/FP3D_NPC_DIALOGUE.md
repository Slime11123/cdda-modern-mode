# 3D NPC 鼠标对话界面

2026-11-01。按用户截图及要求，将普通 NPC 对话换为黄白文字、暖金高亮、半透明暗底，颜色沿用生存面板。

左上角显示当前 NPC 的图块头像，组合性别、衣物、变异及替代外观，裁切上半身。使用现有图块素材，不生成额外人物画像。上方为独立滚动的交谈记录，下方为整行可点击、自动换行的回复；底部提供审视对方、估测状态、评估性格、叫喊、观察态度按钮。右上角可以结束对话；原版没有安全退出项时禁用该按钮。

单击回复直接提交对应索引，不需要再按回车。鼠标滚轮浏览列表及记录，危险后果显示可点击的继续／返回确认框。每个新话题滚动到最新交谈记录，回复从顶部开始。720p、1080p 及生存面板 100%／150% 缩放均可使用，小屏底部操作分两行。

后续反馈修正：底部五个操作直接将原版结果追加至交谈记录，并滚动至最新结果，省去“好的。”确认页。保留当前话题、回复选择和回复滚动位置，不重复进入当前话题或重放其效果；叫喊仍在实际点击后执行一次原版喊话。普通回复及危险选项的确认流程保持。

本次修正的功能回归 135 用例／7071 断言、隐藏图形回归 4340 断言以及 ON/OFF 构建通过。图形回归覆盖结果追加后原回复仍可点击、所选回复保持及记录滚动到底部；未进行桌面人工点击验收。证据在 `qa/npc-toolbar-followup/`，运行包和两个 3D 启动器均更新至 `runtime/npc-toolbar-followup/`。

`fp3d_dialogue` 只排版并返回动作。`dialogue::opt()` 仍执行原版条件复核、特殊话题、任务选择、试验成功率及对话效果。键盘热键保留；2D、电脑交互、非人物事件及调试对话继续使用原界面。交易、训练等后续独立原版界面不在本次重做范围内。

构建时补齐共享工作区中 HUD／快捷栏接口的兼容性：快照接收可变角色引用以重建 UI 物品位置；快捷栏重找物品使用原生递归 `all_items_loc()`，保留口袋内的位置链。后者修复了同时存在的“收起武器后旧快捷栏丢失”回归用例。
