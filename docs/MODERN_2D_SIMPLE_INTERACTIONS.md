# 2D 现代模式：共享简易互动界面

2026-11-03

将此前仍限定在 3D 的三个现代界面入口接入 2D 现代模式，与已有物品面板、右键菜单和 Q 行动轮盘共用。

- **工作台**：右键工作台、台面等物体，选择“查看 / 搜索”，使用现代工作台选项；“制作物品”打开简易制作页，支持配方搜索、筛选、批量和材料详情。请求保留选中的工作台绝对位置，提交时仍检查距离、楼层和原版制作条件。
- **NPC 对话**：右键可见相邻人物选择“交谈”，使用鼠标回复列表、独立交谈记录和底部快捷操作；话题、条件复核、危险确认和实际对话效果继续由原版执行。
- **NPC 交易**：对话进入交易时，使用现有双栏物品界面，支持搜索、类别、数量、金额与确认；物品转移、价格、信用和容量检查保留原版流程。

共享界面不依赖 3D 场景快照。2D 背景按正常方向显示，界面底色与 2D 生存面板一致，防止嵌套对话/交易界面的旧文字透出。3D 的场景背景与原版经典模式入口按原有方式工作。原有容器物品面板、Tab 生存菜单、Q 轮盘、圆形移镜及右键菜单修复包含在当前运行包中。
