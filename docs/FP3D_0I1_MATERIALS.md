# P4 图块材质与精灵

## 已完成的静态材质部分

主要素材为用户指定的 UndeadPeople，安装来源及哈希见 `FP3D_UNDEADPEOPLE.md`。静态材质及可见实体精灵已通过独立运行目录的检查，随视野修复更新默认演示。

`cata_tiles::load_tileset()` 在原版主图块加载完成后，把只读资源共享引用交给 `fp3d_materials`。原版强制重载开始前先撤销旧资源引用，避免加载期间的事件刷新访问正在替换的资源；完成后重建。没有修改原版类布局或读图规则。

材质解析沿用原版季节查询及已知地形静态 `looks_like` 链，按拥有自身数据的快照 ID 取图。变体选择使用稳定 ID 种子，不消耗世界随机数。只在出现新材质、季节变化或换包时生成纹理槽。

原版 `texture::render_copy_ex()` 将背景/前景复制到 1024×1024 SDL 渲染纹理，随后通过 [SDL2 的 GL 绑定接口](https://wiki.libsdl.org/SDL2/SDL_GL_BindTexture)供现有第一人称 pass 使用。全程没有图形读回或每帧 PNG 上传；SDL 渲染目标、视口、缩放、裁剪、颜色与混合状态会还原。缺失素材显示备用棋盘图案，接口不支持时保留无贴图几何与原版 2D 回退。

目前是通用几何表面应用已有图块，尚未为所有物体制作专用侧面。

## 可见实体精灵

快照只在实时可见格中继续使用原版 `avatar::sees()` 检查生物；物品使用原版容器、物品可见性及场效果显示规则，只取地面最上层物品。记忆格和失效可见性缓存不采集实时实体。NPC 基础外观、衣物/变异层、物品变体及季节/静态回退均复制为自有数据，不保留世界对象指针。

绘制采用具有深度遮挡的直立透明裁切精灵，复用图块材质图集；不会把透明矩形盖在墙前。复制外观类怪物暂用中性占位，不暴露真实种类。家具、车辆、复杂连接图块及专用立面仍待后续阶段。

新增检查：`p4-field-final.log` 16 个用例、571 项断言通过，包含墙后实体、隐形、容器、场效果、NPC 层叠、自有快照与 RNG 不变。`p4-gl-gates.log` 实际隐藏窗口 OpenGL 检查 46 项断言通过，覆盖两款图块、墙体遮挡、精灵轮廓及 NPC 衣服；只有明确选择的图形测试才执行有限的诊断读回，正常渲染路径没有读回。扩大视野后的复验见 `FP3D_0I1_VIEW_RANGE.md`。

## 验证结果

- 首次实机在同一避难所显示道路及室内地板；12 种地形均找到素材，日志 `p4-first-textures.log`，截图 `p4-first-textures.png`。
- `p4-hotload-selftest.log`：使用独立副本，通过原版 `game::reload_tileset()` 执行 UndeadPeople→RetroDays→UndeadPeople。三次检查均为 `world_unchanged=1, atlas_ready=1`，最终 `passed=1`；初始位置 `[3564,1856,0]`、行动点 68、时间 5212808，生命值与耐力也保持。两个图块包每次均重建 12 个槽，缺失数为零。
- `p4-renderer-tests.log`：10 个用例、511 项断言通过。新增季节/静态回退、未知 ID、稳定选图不推进 RNG，以及纯内存 SDL 软件渲染器上的备用图块、完整状态恢复、无 GL 安全回退与重载恢复。离屏测试不创建桌面窗口、不做 GPU 读回。
- P4 Feature OFF 构建通过；`p4-off-check.json` 确认无直接 OpenGL 导入，随后 ON 恢复构建成功。

自动换包测试仅由明确设置 `CDDA_FP3D_TILESET_SELFTEST=1` 的独立 QA 进程触发。正常游戏不会改选项或启动该测试。

桌面工具收到实体 Esc 的停止信号后，已停止窗口操作；继续代码、离屏测试和报告工作。后续新增精灵的实机检查另行登记。
