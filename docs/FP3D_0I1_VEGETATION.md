# X 形植物模型

2026-10-27，按用户提供的交叉贴图参考实现；后续要求已把树木加入范围。

后续修订：最矮普通草及枯草已改为仅地面，灌木宽高提升至 1.2 米；以下首次实现记录中的尺寸与截图保留作历史对照，当前状态见 `FP3D_0I1_VISUAL_TUNING.md`。

草、长草、灌木、花、幼树及成熟树采用两组固定、互相垂直的斜向面，从上方看为 X 形，双面可见，使用深度测试和透明裁切。植物不随镜头旋转。

尺寸为展示近似值：普通草 0.3 米、长草 0.65 米、花 0.5 米、灌木 0.9 米、幼树 2.2 米、成熟树 5 米；树宽随高度扩大。普通草地原图不透明，因此用同一纹理绘制草叶轮廓几何，地面继续保留草地。灌木和树木下方绘制泥土，避免把完整植物重复平铺在地面。

图像来自现有图块包，只取植物前景，去掉其地面背景，沿用季节和静态 `looks_like` 回退。家具类花草也可显示。没有改动原图文件、地图内容、采集规则、碰撞、回合耗时或存档格式。

原版可见性继续决定快照内容；实时家具只在可见格读取，隐藏处使用已有地形和装饰记忆。新增测试覆盖树木/幼树/低矮植物识别、隐藏家具不泄露及角色状态不变。
