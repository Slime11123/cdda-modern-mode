# 生物放大与 3D 场景独立显示

2026-10-27，按用户三项反馈修订。

## 显示尺寸

所有生物的 3D 精灵尺寸在原有大小分类基础上放大 20%，NPC/普通僵尸的展示画布高度由 1.8 调至 2.16 米，宽高同比增加，保留图块自身比例。地面物品、手持物品、植物、原版生物体型、碰撞和攻击距离不变；2D 图块尺寸不改。

## 树木上的 2D 残影

UndeadPeople 树木前景含有大量 alpha 值在 128–254 的边缘像素。原合成路径先做 3D 透明裁切，再把整个 3D 画面按 alpha 混合到原版地图上，因此仍有半透明边缘把 2D 地图透了出来。

完整 3D 场景现使用不透明复制替换地图窗口，保留 3D 场景内的透明裁切、遮挡及天空；不再按场景纹理的 alpha 混合下方地图。主菜单透明立方体仍沿用原来的透明合成，原版 UI 区域和 GL 状态恢复不变。

## 无须先在 2D 探索

新增 `fp3d_snapshot::prepare_view()`，在游戏线程准备原版光照/视线和地图记忆缓存；快照发布移到 `wnoutrefresh(w_terrain)` 之前，不等待 2D Tiles 绘制或写入记忆。

实时地形改用原版 `avatar::sees()` 查询光照和 LOS，不再把 2D tile visibility mask、2D 视口边界或记忆内容作为实时可见性的条件。原版角色当前能看见的新区域，即使从未出现在 2D 探索记录中也会直接显示。失效缓存仍保守回退，墙后及黑暗中的未知实时数据仍不读取；已知的隐藏地形只允许历史记忆。没有加载现实泡之外的地图或修改角色视力属性。

## 验证与交付

- `qa/0i1/view-isolation-final-cpu.log`：24 用例、721 项断言通过，包括清空 25 格外地形记忆、隐藏其 2D 显示 mask 后，3D 仍按原版 LOS 显示；准备/采集后记忆仍为空，位置、时间、行动点、RNG 保持。另有夜间未知地形不可见检查。
- `qa/0i1/view-isolation-gl.log`：246 项实际 OpenGL 检查通过。将整个 2D 底色分别改成红色和蓝色，完整含树木的 3D 输出逐像素相同；两款图块均通过。NPC/僵尸放大后的样图已目视检查，原有比例、遮挡、手持物品、天空和远景回归保持通过。
- `qa/0i1/view-isolation-off-build.log` / `view-isolation-off-check.json`：关闭功能构建通过，无直接 OpenGL 导入；随后 ON 恢复构建通过，运行程序为 `runtime/view-isolation`。
- 原有运行窗口保留，启动器更新及程序哈希记录见 `view-isolation-delivery.json`。用户目录仍为 `runtime/0i1/user`。
