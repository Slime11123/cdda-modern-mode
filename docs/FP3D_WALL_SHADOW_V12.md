# CDDA 第一人称 3D：Ultra 墙面三角形阴影修复 v12

日期：2026-11-08

## 用户反馈

开启 Ultra 后太阳阴影恢复，但一整排建筑外墙的上部出现每个瓦块重复的三角形深色斑块。此前禁用太阳阴影时斑块消失，表明问题来自太阳阴影投射或其接收着色，而非普通贴图本身。目标是去除假阴影，同时保留车辆、路灯、建筑与地面深色太阳投影。

## 这次实际源码修改

1. `src/fp3d_shadow.cpp` 的墙面遮挡体不再逐瓦块绘制 .502m 半径盒：相邻独立盒的每一段内部端盖可能沿斜向日照投到隔壁墙上，在整面墙上制造周期性三角形自阴影。现在只遍历已经可见、已知的完整实心墙瓦块，沿 X 或 Z 合并为连续深度遮挡体，遇到门窗则中断。长边延伸到实际可见墙模型端部，短边向墙内部收缩 12mm（半宽 .478m；可见墙半宽 .49m）。不修改实际世界几何、碰撞、门窗和原版 2D。
2. `src/fp3d_shaderpacks.cpp`：接收面根据深度导数求可见表面法线，并使用朝向太阳的直接光比例；移除背光墙仍有 16% 阴影调制的底数，让背光墙和天花板下表面不再错误压暗其间接/环境光。正常面向太阳的地面、建筑外立面仍可接收暗色太阳阴影。
3. 不改 Ultra 的 2048² / 28m 近场和 1536² / 96m 远场两级 FBO、PCF 混合、太阳高度、原有 Photon 色调，也不调整存档。

## 仍需玩家同场景确认

QA 实验世界中的墙面镜头与用户截图里的长黑色外墙并非同一建筑、太阳角度和贴图。上述数据验证了功能与差异，**不能据此断言截图中的所有三角形斑块已经完全消失**。

退出旧游戏后从项目根目录 `启动3D操作修复验证.cmd` 进入当前版本；在原来那面墙、相同时间天气和 Ultra 设置下复查。如果还存在周期斑块，优先继续用相同位置的 Ultra 有阴影/无阴影截图对比，排查墙顶单片天花投影或世界空间深度坐标误差。不要为了掩盖问题而关闭整个太阳阴影。
