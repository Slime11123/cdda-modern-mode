## 4. P0：建立可重复的缺块证据

1. 优先在用户场景中选择三个点：草地蓝色空缺、建筑外沿空缺、用户可确认的一处缺墙。对每个点记录绝对地图坐标与 z 层、地形 ID、玩家坐标和视角。不要仅凭屏幕像素推断地图坐标。
2. 同一回合固定玩家，比较第一人称与俯视；俯视方位 0/90/180/270 度及距离 6/18/48。随后移动一格再返回，记录缺口是否随相机、回合或刷新变化。
3. 用原版地图数据／2D 对照判定真实地形：确实有地板或墙、真实洞口、水面、未知还是记忆。调试查看地图可用于诊断，但这些调试数据不能进入正常渲染快照。
4. 在隔离测试地图中构造最小复现：连续草地、道路、实体墙与转角、门窗、两层建筑；再逐项加入天窗、楼梯、车辆和剖切，避免复杂地图同时引入多个变量。
5. 若原存档暂不可得，继续最小场景和静态审查，明确标注尚未复现原图，不凭猜测修改正式可见性规则。

产出：缺块坐标表、固定相机前后截图、运行版本记录和至少一个可重复失败场景。

## 5. P1：逐格追踪，定位第一个丢失环节

增加仅用于 QA 的定点诊断，默认关闭，限制坐标范围和日志频率。优先复用现有统计；建议字段如下，名称可按代码风格调整：

`position / terrain / knowledge / exterior_only / floor_present / ceiling_present / open_air / over_avatar_region / snapshot_skip_reason / geometry_skip_reason / chunk_key / render_generation / mesh_signature / frustum_result / material / submitted_faces`。

对被 continue 跳过、根本没有 cell 的坐标，也应能记录拒绝原因。只给已生成 cell 打日志会漏掉最关键路径。

按以下顺序判断，每次只改变一个诊断变量：

1. **快照不存在**：检查感知、记忆、采样范围、z 范围、空地过滤和剖切。合法未知区域不属于真实地面生成故障。
2. **快照存在但未生成几何**：记录 `draw_cell()` 中具体拒绝条件、墙体分类和特殊模型接管结果。
3. **几何有但未提交**：对照临时禁用视锥裁剪的结果；可视化分块包围范围。
4. **强制重建后恢复**：对照临时绕过显示列表复用，追踪缺少的缓存依赖。
5. **几何已提交但像素缺失**：使用纯色不透明材质、深度可视化，逐项检查 alpha、深度写入、绕序、背面剔除和各通道 GL 状态恢复。光影开启／关闭分别对照。

禁用优化和强制材质只能用于定位。不能把“调试模式没洞”视为正式修复。

## 6. P2：按确认的原因实施最小修复

### A. 快照或感知边界漏面

- 对原版应可见的实体表面，修正具体判断或坐标／缓存更新问题；不要把所有相邻格自动升级为 visible。
- 现有外壳补偿若不足，严格限定为有依据的结构表面，不复制不可见家具、物品、生物和内部布局。目标拾取仍拒绝 `exterior_only`。
- 对合法未知区域露出天空的问题，单独记录为“未知区域呈现”问题。若需要遮蔽，只使用不带真实未知地形细节的表现层遮罩，不伪造可行走地板、不改变知识和交互；先确认这是复现中的实际原因再实现。
- 检查快照采样边界与可见画面覆盖关系。不能以扩大相机范围为理由扩大玩家感知、加载／生成未知地图。

### B. 剖切误删

- 核对连通区、墙体边圈、关闭的门、相邻房间和 z 条件；保证只删除玩家所属区域的遮挡上层及天花板。
- 当前层地板和墙体保留。进出房间、开关门、上下楼、F6 切换后更新剖切数据及相关缓存。
- 修复后同时验证“室内可看清”和“室外建筑完整”，不把永久隐藏整栋屋顶作为修复。

### C. 特殊地形过滤范围过宽

- 分别核验 `under_glass`、`hide_vehicle_roof_ghost`、楼梯开口、无线电塔和树冠条件，重点检查世界／分块局部坐标和楼层偏移。
- 若通用地板被专用模型替代，验证替代面确实覆盖正确位置；若是合法开口，则保留，不填死。
- 墙体问题核对 terrain 分类、墙／门／窗邻接和实际发出的面；不能简单把所有不可通行地形都改成实心墙。

### D. 裁剪或分块缓存

- 包围范围需涵盖实际生成的墙高、楼板厚度、向下结构和跨格模型；检查地图原点变化、负坐标及跨 8×8 分块边界。
- 逐项比较几何生成读取的依赖与 signature 输入，尤其上下层材质／类型、天窗遮蔽集合、车辆屋顶抑制和邻接状态。已有 `floor_present`、`ceiling_present` 等字段已参与签名，不要重复添加而忽略真正缺失依赖。
- 仅对证据确认的依赖补充签名或失效传播；邻块变更时更新受影响块。禁止以每帧全场景重建交付。

### E. 材质与渲染状态

- 如果实体面因透明贴图被抠空，修复对应材质分类或不透明基底；玻璃、栅栏、植被保持正确透明。
- 如果贴图查找失败，保留已有几何回退并修正映射；不要把材质问题误修为地图问题。
- 修复实际出错通道的状态设置／恢复，确保主颜色、深度、阴影及辅助通道使用一致的几何与相机语义。
