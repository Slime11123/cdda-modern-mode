## 3. 目标布局

采用居中的横向紧凑面板，取消当前左侧导航栏与顶部三标签；上下固定，中间滚动。

```text
┌─ 创建世界 ────────────────────────────────────────────┐
│       世界名称： [ 当前世界名称                ] [随机名称] │
├───────────────────────────────────────────────────────┤
│ 城市                         │ [‹] [ 当前城市预设 ] [›] │
│ 当前档位的说明，可自然换行     │                         │
│ 难度                         │ [‹] [ 当前难度预设 ] [›] │
│ 当前档位的说明，可自然换行     │                         │
│ 生成随机 NPC                 │ [‹] [ 当前 NPC 预设] [›] │
│ 当前档位的说明，可自然换行     │                       ▒ │
├───────────────────────────────────────────────────────┤
│           [模组设置] [高级设置] [重置]                 │
│           [  随机  ] [  完成  ] [返回]                 │
└───────────────────────────────────────────────────────┘
```

### 3.1 布局约束

1. 标题左对齐；第一行包含世界名称标签、主要名称框、随机名称按钮。名称框可点击进入现有编辑对话框，不强制新增内嵌输入系统。
2. 中间区域每个设置占一整行：左侧“名称 + 当前档位说明”，右侧“上一档按钮 + 档位名称框 + 下一档按钮”。所有行共用一条列分界，左右内容按同一行高度对齐。
3. 左列约占 43%，右列约占 57%，允许按字体与可用空间微调；说明使用真实换行高度，不按固定三行强行截断。
4. 截图只展示三项不代表只能有三项。继续枚举 `WORLDGEN` 的全部预设，超出高度时在中间区域滚动，右边显示滚动条。
5. 底部六个按钮按图示顺序排列，三列等宽、两行等高，整体居中，始终可见；不能继续受 `all_sliders_drawn` 条件控制而消失。
6. 常规宽屏下以面板宽高约 2.3:1 作为视觉起点，最终让当前字体和内容决定最小高度。不得为了比例缩小中文到难以阅读。
7. 采用当前窗口坐标和字体度量计算布局，不能直接照搬图片像素。小窗口优先减少外边距、增加中间滚动；名称区空间不足时可换行，底部操作仍需完整可达。
8. 保留现有边框、字体和主题质感；不增加插画、世界预览、侧边栏、装饰卡片或额外信息区。

### 3.2 配色：以当前实际页面为准

实施前在当前配置下保存“创建世界”基线截图。颜色优先复用现有语义色和绘制通道，不从参考图片取色。

当前基本页源码使用 `BORDER_COLOR`、`c_white`、`c_light_gray`、`c_yellow`、`c_light_green` 和 `hilite(...)`。保留这些语义及用户颜色配置；背景沿用原页面背景。不要为单页改动修改全局调色板。

如确实需要以现有现代 UI 绘制能力补充按钮外观，先确认实际主题路由，并复用已有主题：`fp3d_simple_ui::scoped_theme` 中 WindowBg 为 `(.035, .033, .03)`、Button 为 `(.12, .115, .10)`、高亮金色为 `(.88, .66, .32)`，各状态透明度也已有定义。上述数值仅用于核对，不能据此强制把当前 catacurses 页换成另一套颜色。

返回按钮使用项目已有返回/取消语义，不因参考图为红色就新增红色。焦点、悬停和按下状态沿用当前主题。

## 4. 交互和数据约束

| 控件 | 行为 |
| --- | --- |
| 世界名称 | 打开现有名称编辑；取消不丢失原名称；中文、长名称按显示宽度处理。 |
| 随机名称 | 仅调用现有随机命名逻辑，不随机化世界设置。 |
| 左右箭头 | 每次改变一档，继续使用 `count()`、`level_name()`、`apply_opts()`；到边界不循环，按当前 clamp 语义处理。 |
| 中间档位框 | 展示当前档位，点击可选中该行以便键盘操作；不暗中随机化、不继续作为滑条轨道使用。 |
| 模组设置 | 调用现有模组选择；返回后名称、预设、已改高级选项和滚动位置保留。 |
| 高级设置 | 默认显示同一面板内的高级设置视图，并提供明确的“基本设置”返回入口；保留当前可编辑的高级项，不能因删除 Options 标签而丢失入口。 |
| 重置 | 复用现有确认和重置范围，包括世界默认选项、模组默认列表、预设档位；不要额外重置名称。 |
| 随机 | 使用每项的 `random_level()`，并确认生成档位通过 `apply_opts()` 写入 WORLD_OPTIONS；名称与模组不受影响。 |
| 完成 | 走现有名称校验、空名称处理、完成确认与外层模组兼容检查；成功前不另存一份世界。 |
| 返回 / Esc | 复用现有放弃创建确认；取消确认留在本页，确认退出不产生新世界。 |

高级设置说明：当前基本页 `active_tab == 1` 显示 `WORLD_END`、`WANDER_SPAWNS`、`BLACK_ROAD`、`CHARACTER_POINT_POOLS`、`META_PROGRESS` 五项。最低要求是完整保留这些项目及其语义；本任务不要求扩展为所有世界选项。若复用完整高级编辑器，先核对返回值、确认流程与草稿生命周期，不得意外完成创建或覆盖名称。

如高级修改使某个预设无法准确表示实际值，该行显示“自定义”。再次选择预设时沿用已有的重置提示语义，用户取消后不得改动任何实际选项。不能仅修改显示文字而不写入数据。

键盘与鼠标共用动作处理，保留现有快捷键绑定；焦点覆盖名称、随机名称、所有预设和六个底部操作。滚轮只移动中间列表，不改变设置值。滚动和缩放后，点击区域必须与绘制区域一致，不可点击已被裁剪的行。
