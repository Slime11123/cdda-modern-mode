# 原版信息条件与字体字距修复

2026-11-01，运行包 `runtime/native-info-font`。

## 信息显示

0.I-1 的 `data/changelog.txt` 已记录移除 Self-Aware 特质，原版数字生命侧边栏是 widget 样式选择，不是角色拥有的特质。本次不新增游戏特质，3D 默认采用原版非数字呈现。

- HUD 顶部删除总 HP 数字，耐力使用原版 `get_stamina_bar`；健康页、装备侧栏和展开信息共用 `health_text`。部位生命采用 `get_hp_bar`，无痛觉角色使用原版伤势等级词，断肢显示 `==%==`；调试模式可显示生命/耐力诊断数字。
- 移除现代健康页连续精确生命进度条；保留原版累赘、属性、技能和物品计数等正常可知数字。身体轮廓继续使用原版分档颜色，左右肢体保持独立。
- 饥渴使用 `display::hunger_text_color` / `thirst_text_color`；疲惫进程使用分段条。疼痛继续使用 `display::pain_text_color`，原版 `got_checked` 状态存在时可显示精确疼痛。
- HUD 和入场资料共用 `display::time_string` 与 `display::get_temp`：有手表/原版计时能力才显示精确时刻，否则用原版时段或 `???`；有测温设备或 `THERMOMETER` 角色标记才显示温度，否则为 `-`。入场日期使用原版日期文本，不再从完整日历字符串泄露秒数。
- 仅修改展示，不改变世界、伤害、属性、存档或角色特质。

## 字体

SDL_ttf 的单字表面包含上下透明行距；之前把整张表面等比缩小，导致汉字只占 18 像素却仍按 24 像素前进。本次按实际 alpha 笔画高度与字符格宽度计算统一缩放比例，尽可能保留行基线，仅允许透明留白超出字符格。可见笔画完整保留，字格和布局宽度不变。

雅黑 24 号“温”，12×24 字格：笔画范围从 18×17 恢复为 24×22。测试覆盖中英文宽字母、下伸部字母、汉字、标点、不同字格和抗锯齿开关；新增汉字填满字格的回归约束。
