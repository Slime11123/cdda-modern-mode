# 隔离的实机战斗测试设置

此目录不会被默认游戏或启动器加载。仅用于可丢弃的 QA 世界副本。

将 `combat_fixture` 复制到该副本用户目录的 `mods/fp3d_qa_fixture`，并在该副本世界的 `mods.json` 中追加 `fp3d_qa_fixture`，然后通过原版 `--world` 参数读取该世界。

原版 EVENT EOC 在每次读档时于角色东侧一格生成一只普通 `mon_zombie`；近战、命中、行动点、AI、怪物属性均沿用原版。东侧位置不可放置时不生成目标。测试方向键攻击、界面和保存。每次重新载入都会再次生成目标，不能用于正式游玩，也不能以该测试宣称自然世界生成场景已通过。

实际测试目录为项目根 `qa/0i1/combat-fixture-original/`。为避开桌面工具对 `!` 的注入问题，该副本将安全模式快捷键改为 `z`；正常演示启动器的快捷键不变。
